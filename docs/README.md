# Спецификация SberOS DE

## Назначение

Документы описывают целевую среду и её требования. Исходный бриф — концепция инициативы; наличие требования не подтверждает его реализацию.

## Навигация

- [Каталог сценариев и тематические правила](rules/README.md)
- [Открытые вопросы](rules/open-questions.md)
- [Архитектурные решения и их статусы](adr/README.md)
- [План и состояние работ](tasks/README.md)
- [Источники и их перенос](#источники)

Перед изменением поведения проверьте применимые правила и статусы ADR. В задаче указывайте затронутые ID сценариев, выполненные проверки и ограничения результата. Требования и решения хранятся в `rules/` и `adr/`; критерии, прогресс и проверки работ — в карточках `tasks/`.

## Структура

- `adr/` — решения, их основания, область действия и последствия.
- `rules/` — продуктовые рамки, наблюдаемое поведение и приёмка.
- `sources/` — исходные материалы и их документированные слепки.
- `tasks/` — текущие работы и архив закрытых карточек.
- `mock/` — интерактивные визуальные макеты; общий [экран выбора](mock/index.html) ведёт к Smart Panel и входу/блокировке.

## Кодовые базы и UI Kit

Сравниваются три основы по [ADR-0010](adr/0010-base-comparison.md): [`shell/`](../shell/) (Sirca), [`quickshell/`](../quickshell/) (NextKDE) и [`plasma-theme/`](../plasma-theme/) (AeroThemePlasma). Рабочие копии отделены от исходников в `refs/`; референсы не изменять.

[`ui-kit/`](../ui-kit/README.md) — общий набор QML/C++ компонентов, темы и токенов для оболочки и приложений. Его [API-контракт](../ui-kit/docs/API.md) — основной справочник по использованию. UI Kit не содержит логику рабочего стола или предметную логику приложений.

## Действующие решения проекта

- [ADR-0006](adr/0006-settings-ui-kit.md): собственные настройки оболочки используют UI Kit.
- [ADR-0007](adr/0007-ui-kit-api-contract.md): API-контракт UI Kit — основной справочник.
- [ADR-0008](adr/0008-unified-bottom-panel.md): в Sirca используется одна нижняя панель.
- [ADR-0009](adr/0009-smart-panel-scope.md): Smart Panel переносится на собственный стек с зафиксированными границами MVP.
- [ADR-0011](adr/0011-mock-visual-target.md): HTML-мок — визуальная цель MVP для Sirca и Quickshell; приёмка каждой основы отдельная.

Подробные требования и актуальные проверки находятся в профильных rules и карточках задач. Этот раздел — краткий указатель, а не отдельный источник требований.
