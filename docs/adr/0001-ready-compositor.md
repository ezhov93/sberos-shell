# ADR-0001: Готовый композитор вместо собственной разработки

- **Статус:** Ограничение концепции из брифа; конкретный композитор не выбран.
- **Основание:** Бриф, раздел 4; презентация, слайды 7–8. См. [источники](../README.md#источники-и-границы-переноса).
- **Происхождение записи:** реконструкция по исходным материалам; отдельное утверждение ADR не зафиксировано.

## Контекст

Собственная графическая среда должна повысить управляемость UX без разработки всего графического стека.

## Решение или предложение

Использовать готовую технологию композиции окон, дисплеев, фокуса и ввода. Самостоятельно развивать интерфейс и интеграцию.

## Альтернативы и границы

Собственный композитор исключён рамками брифа. Готовые композиторы ещё предстоит сравнить.

## Последствия

Потребуются интеграционный слой, проверка мониторов и приложений, оценка сопровождения. Нельзя обещать восстановление сессии при любом отказе графического ядра.

## Открытые вопросы

Выбор реализации, доступные протоколы и API, лицензирование, графическая и аппаратная матрица.
