# ADR-0002: Единая Wayland-сессия

- **Статус:** Ограничение концепции из брифа; миграция не подтверждена.
- **Основание:** Бриф, разделы 3–5; презентация, слайды 6, 9. См. [источники](../README.md#источники-и-границы-переноса).
- **Происхождение записи:** реконструкция по исходным материалам; отдельное утверждение ADR не зафиксировано.

## Контекст

Сопровождение отдельных X11- и Wayland-сессий увеличивает число вариантов проверки.

## Решение или предложение

Целевая графическая сессия — Wayland. Для необходимых X11-приложений допускается XWayland.

## Альтернативы и границы

Отдельная X11-сессия не входит в целевые ограничения. Совместимость через XWayland необходимо проверить для обязательных приложений.

## Последствия

Все поддерживаемые сценарии требуют испытаний в Wayland, включая ввод, захват экрана, масштабирование и несколько мониторов. Сам выбор Wayland не доказывает улучшения качества.

## Открытые вопросы

Матрица приложений и оборудования, ограничения совместимости, критерии готовности миграции.
