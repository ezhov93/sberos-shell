# ADR-0003: Единый API рабочего пространства и безопасный AI-доступ

- **Статус:** Архитектурное направление концепции; контракт не определён.
- **Основание:** Бриф, разделы 3–4; презентация, слайд 10. См. [источники](../README.md#источники-и-границы-переноса).
- **Происхождение записи:** реконструкция по исходным материалам; отдельное утверждение ADR не зафиксировано.

## Контекст

Управление рабочим пространством через AI требует формальных действий и наблюдаемого состояния.

## Решение или предложение

Предусмотреть общий API команд, состояний и событий для собственных функций SberOS и AI. MCP — предусмотренный путь AI-интеграции. Учитывать разрешения, безопасность и аудит.

## Альтернативы и границы

Управление AI только движениями мыши не является целевой моделью презентации. Протокол внутреннего IPC и способ MCP-интеграции источники не выбирают.

## Последствия

Потребуются контракт операций, модель объектов и событий, ограничения доступа и проверка аудита. Нельзя предоставлять агенту неограниченный системный доступ.

## Открытые вопросы

Авторизация, владельцы действий, подтверждения опасных операций, схема аудита, версии API, поведение при ошибках.
