# ADR-0006: Настройки оболочки на общем UI Kit

- **Статус:** Принято; окно настроек переведено на UI Kit, проверки в Wayland-сессии предстоят.
- **Дата:** 2026-10-22.
- **Основание и ответственный за решение:** прямое указание пользователя проекта перевести настройки на UI Kit в рабочем чате.
- **Происхождение записи:** решение проекта после переноса исходных материалов; не реконструкция брифа.

## Контекст

В Sirca есть два отдельных интерфейса: собственное окно `shell/shell/qml/Settings.qml` и внешнее приложение KDE `systemsettings`. Собственное окно использует самописные элементы Glass и сохраняет параметры оболочки. Системное приложение и его KCM-модули управляют сетью, звуком, экранами и другими параметрами KDE; их исходники не входят в `shell/`.

`ui-kit/` принят как общая библиотека интерфейса оболочки SberOS и приложений. Окно настроек оболочки переводится на её компоненты и тему.

## Решение

- Переписать собственное окно настроек оболочки с использованием модулей `Sber.Controls`, `Sber.Theme` и других модулей UI Kit по необходимости.
- Общие элементы, токены цветов, типографику, размеры и состояния развивать в `ui-kit/` и переиспользовать. Разделы настроек, привязки к конфигурации и вызовы сервисов оставлять в `shell/`.
- Сохранить доступные параметры, применение изменений без перезапуска, сброс отдельных параметров и открытие нужного раздела через существующие точки входа.
- Сохранить совместимость с `~/.config/sirca-shell/config.json` и существующими D-Bus-методами `openSettings` и `openSettingsPage`.
- Системные параметры пока открывать через существующие интеграции KDE. Замена `systemsettings` и перенос KCM-модулей требуют отдельного решения.

## Границы

Решение касается окна настроек оболочки. Оно не утверждает перенос всех экранов оболочки, замену KDE System Settings или завершение интеграции UI Kit. Обсуждение оценки объёма кода без прозрачности, блюра и апплетов не является решением об их удалении.

## Последствия и проверка

Потребуется подключить QML-модули UI Kit и ресурсы темы к сборке и запуску оболочки. Способ поставки зависимости должен быть описан вместе с реализацией.

Правила миграции и проверки: [настройки и UI Kit](../rules/settings-ui-kit.md). Основные сценарии: `09-21`, `09-24`; проверки оформления связаны с `09-02`, `09-19`, сохранение выбора обоев — с `09-01`. Это область регрессионных проверок, а не подтверждение полного покрытия сценариев.

## Текущее состояние

`Settings.qml` использует Sber.Controls и Sber.Theme. В сборку и QML-движки оболочки добавлен путь `SBER_QML_IMPORT_PATH`; библиотека собирается отдельно. Сохранены все 35 ключей строк настроек и прежние точки входа. Изолированные проверки и скриншоты описаны в [отчёте](../../shell/shell/tests/settings/README.md). Полная проверка сценариев в Wayland-сессии не выполнена.
