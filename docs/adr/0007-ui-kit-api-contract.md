# ADR-0007: API-контракт UI Kit как основной справочник

- **Статус:** Принято для разработки потребителей UI Kit.
- **Дата:** 2026-10-22.
- **Основание и ответственный за решение:** прямое указание пользователя проекта составить API-контракт и использовать его вместо повторного чтения кода библиотеки.
- **Происхождение записи:** решение проекта, не реконструкция исходного брифа.

## Решение

Основной источник для использования UI Kit в оболочке и приложениях —
[API-контракт](../../ui-kit/docs/API.md), дополненный каталогами объявлений
и токенов. Он описывает текущий снимок библиотеки, включая ограничения.

При обычном использовании описанного API разработчик обращается к контракту.
При недостатке сведений, ошибке выполнения или устаревании документации изучает
относящиеся к вопросу исходники и дополняет контракт в той же задаче.
Изменение самой библиотеки требует чтения её реализации по необходимости.

## Актуальность

Вместе с изменениями библиотеки обновлять смысловое описание контракта,
каталоги и отпечаток исходников. Команда `python3 ui-kit/tools/api_contract.py --check`
выявляет изменения источников и расхождения каталогов; `--write` перегенерирует
каталоги после проверки контракта разработчиком. Автоматическое извлечение
объявлений не проверяет полноту описания, семантику и поведение Qt.

## Границы

Это документальный контракт QML API, а не новый бинарный ABI, API рабочего
пространства или модель разрешений. Он не подтверждает выполнение сценариев
и не заменяет сборку и проверки. Интеграция настроек по
[ADR-0006](0006-settings-ui-kit.md) остаётся отдельной работой.
