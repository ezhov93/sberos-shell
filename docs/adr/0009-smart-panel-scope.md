# ADR-0009: Рамки переноса Smart Panel на собственный стек

- **Статус:** Принято для текущей адаптации; реализация блоков запланирована.
- **Дата:** 2026-10-22.
- **Основание:** прямые ответы пользователя проекта в PANEL-000.
- **Происхождение:** решение проекта; не изменение статуса исходной вики.

## Решение

Функциональность и внешний вид определяются требованиями и макетами Smart Panel,
с учётом явно записанных отклонений. Сохраняем свой стек Qt/QML и общий UI Kit,
текущая основа — KWin/Wayland. Под GNOME не адаптируем, расширение GNOME не создаём.
Это ограниченное решение для текущей работы, не Go/No-Go всей DE из ADR-0004.
Отдельная X11-сессия по-прежнему вне целевой модели по ADR-0002.

Корпоративные настройки не входят в MVP. Их пункт в меню Сбер отсутствует;
пункт настроек открывает собственные настройки shell, не KDE systemsettings.
Вместо пяти иконок источника получаем четыре: настройки shell, терминал,
питание/сессия, сворачивание. GNOME Terminal не является обязательной зависимостью;
системную точку входа терминала определить в PANEL-002.

Оформление следует SHELL-001: палитра UI Kit и непрозрачные поверхности без
фонового blur, несмотря на прозрачность исходных картинок.

## Поставка и последствия

GNOME rollout и перенос закрепов GNOME не входят в эту работу. Промышленная
поставка собственной оболочки требует отдельной задачи и проверок; здесь она
не реализована. Unified/split остаются режимами Sirca по ADR-0008, split не
является возвратом к GNOME. Правила ручного запуска разработчика сохраняются.

Неопределённые интеграционные контракты, размеры и конфликты поведения остаются
в задачах соответствующих блоков; закрытие PANEL-000 не означает их разрешения
или реализации всех FT. Подробная [таблица переноса](../rules/panel-adaptation.md)
фиксирует отклонения без изменения исходников.
