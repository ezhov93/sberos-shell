# ADR-0012: Один апплет приложений Plasma

- **Статус:** Принято 2026-10-27.
- **Основание и ответственный:** прямое решение пользователя объединить Launchpad
  и Task Manager, чтобы упростить дальнейшее раскрытие +N.
- **Область:** рабочая копия `plasma-theme/`, задача ATP-001.

## Контекст

Кнопка Plasma Drawer и SmartTasks были отдельными апплетами. Общую поверхность
рисовал containment панели, связывая геометрию соседних элементов. Для визуальной
подмены всего острова по приёму Dynamic Island понадобилась бы координация
двух апплетов, их фона, состояний и popup.

## Решение

Использовать один KPackage `plasmoids/sberos.smarttasks` с ID
`io.gitgud.wackyideas.smarttasks`. Он владеет кнопкой Launchpad, полноэкранным
меню приложений, одной TasksModel, закреплениями, preview и +N.
Поверхность острова рисует компонент этого апплета; containment передаёт обои,
располагает апплет и сохраняет общий контракт маски/резерва панели.

Отдельный KPackage Drawer удаляется из рабочей копии и пользовательской установки
после резервного копирования. Стартовая раскладка удаляет прежнюю отдельную кнопку
из существующих SberOS-панелей, сохраняя экземпляр SmartTasks и его закрепления.
Новые панели сразу содержат один объединённый апплет.
Сторонние лицензии и атрибуция перенесённых компонентов Drawer/KDE сохраняются.

## Последствия и границы

Место кнопки Launchpad учитывается до расчёта переполнения. Launchpad и popup
задач взаимно исключаются, а открытие другого апплета закрывает Launchpad.
Полноэкранное меню остаётся отдельным DashboardWindow. Первый коммит объединения `5955f49` не вводил
анимацию подмены +N; её механизм принят следующим уточнением ниже.
Sirca, Quickshell, UI Kit и `refs/` этим решением не меняются.

Проверки реализации, снимки и ограничения находятся в
[ATP-001](../tasks/ATP-001.md) и
[unified-applications](../tasks/evidence/ATP-001/unified-applications/README.md).

## Уточнение раскрытия +N, 27.10.2026

После объединения пользователь подтвердил следующий шаг — визуальную подмену
острова по исследованному приёму Dynamic Island. Использовать существующее
native окно fullRepresentation с наложением на исходный остров. Высота PanelView
и резерв рабочего места сохраняются; внутри окна анимируются форма и содержимое,
а компактная поверхность и её маска временно исключаются из панели.
Launchpad входит в сетку первым. Native рамка получает заранее рассчитанные
маски движения и дочерних элементов, без генерации файлов на каждом кадре.
Патч plasma-workspace для расширения исходного окна панели этим вариантом
не требуется. Реализация и ограничения: [ATP-001](../tasks/ATP-001.md),
[applications-reveal](../tasks/evidence/ATP-001/applications-reveal/README.md).
