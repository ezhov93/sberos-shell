# Архитектурные решения

ADR-0001–ADR-0005 восстановлены из концептуальных материалов. Более поздние записи отдельно фиксируют решения проекта с основанием, датой и областью действия. Статус «ограничение концепции» означает явную рамку брифа; «предложено» требует дальнейшего решения. Ни один статус не подтверждает реализацию.

| ADR | Тема | Статус |
| --- | --- | --- |
| [ADR-0001](0001-ready-compositor.md) | Готовый композитор вместо собственной разработки | Ограничение концепции из брифа; конкретный композитор не выбран |
| [ADR-0002](0002-wayland-session.md) | Единая Wayland-сессия | Ограничение концепции из брифа; миграция не подтверждена |
| [ADR-0003](0003-workspace-api.md) | Единый API рабочего пространства и безопасный AI-доступ | Архитектурное направление концепции; контракт не определён |
| [ADR-0004](0004-own-shell.md) | Собственная оболочка поверх готовой графической основы | Sirca выбран как стартовая кодовая база; конечная архитектура требует исследования и Go/No-Go |

## Обновление решений

При утверждении добавить основание, дату и ответственного; при замене сохранить старую запись и ссылку на новый ADR. Это соглашение ведения документации. Не объявлять технологию выбранной только потому, что она встречается в `external/`, `refs/` или макете.
