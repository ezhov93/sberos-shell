# Smart Panel: интерактивный HTML-мок

Открыть `index.html` и перезагрузить вкладку после обновления файлов. Сборка и
сервер не нужны. В «Мок · управление» доступны 26 состояний, тема, прозрачность,
масштаб 1:1 и наложение «Сверить с оригиналом». Ползунок оставляет слева HTML,
справа — SVG, либо PNG для состояний без SVG. H скрывает управление, Esc закрывает
текущий уровень. Все системные действия демонстрационные.

Кнопки, поля, регуляторы, календарь и выдача поиска реализованы HTML. Кнопка
Launchpad открывает полноэкранные приложения; строка Оськи открывает локальную
выдачу приложений и документов, аватар — список уведомлений. Wi-Fi, Bluetooth,
питание и настройки сохраняют значения в памяти страницы. Галерея всех 37 PNG
сохранена отдельно в `references.html`.

## Источники и графика

Основной источник геометрии — восемь [SVG-макетов](../../sources/panel/svg/).
[Скриншоты](../../sources/panel/screenshots/) дополняют состояния и тёмную тему.
ТЗ и решения MVP сохраняют приоритет для поведения.

`tools/extract-svg-assets.py` извлекает из исходных SVG чистые обои, слой значков
рабочего стола, аватар, 32 значка приложений и 24 значка интерфейса/типов файлов.
Контуры и зависимости SVG сохраняются. Большие встроенные растровые изображения
уменьшаются: иконки до 240 px в PNG, обои до 1920×1080 в JPEG; отдельные обои
страницы — WebP. Это производные копии для браузерного мока, исходники не меняются.
`assets/icons.css` встраивает данные масок для локального просмотра.
`assets/manifest.json` содержит SHA-256 оригиналов и извлечённые координаты.
Для повторного извлечения нужен Python 3 с Pillow:

```sh
python3 docs/mock/smart-panel/tools/extract-svg-assets.py
```

В `assets/references/` находятся оптимизированные SVG для наложения. Исходные
SVG содержат текст в контурах: название шрифта из них установить нельзя. В HTML
используется Ubuntu/системный шрифт. Недостающие динамические значки (например,
включённые уведомления) нарисованы в `mock.js`; остальные взяты из SVG.

Фон теперь разделён на чистые обои и слой рабочего стола. В нём нет запечённых
нижних островов. Иконки приложений и аватар больше не вырезаются из скриншота.

## Геометрия

Система координат — 1920×1080. Сцена масштабируется целиком. Эти значения описывают
референс, не утверждают производственный дизайн-контракт.

| Элемент | Координаты/размеры из источников |
| --- | --- |
| Сбер | x=16, y=1000, 72×72 |
| Приложения | x=96, y=1000; 168×72 без Jazz, 224×72 с Jazz |
| Оська | x=732, y=1000, 456×72 |
| Системный остров | x=1668, y=1000, 236×72 |
| Быстрые настройки | x=1416, y=452, 488×540; заголовки «Звук»/«Дисплей», восемь плашек |
| Wi-Fi, раскрытые сети | x=1560, y=396, 344×596 |
| Bluetooth, подключён | x=1560, y=436, 344×556 |
| Календарь | x=1560, y=610, 344×382 в сентябре 2026 |
| Локальный поиск | x=732, y=419, 456×653; четыре приложения, шесть документов |
| Уведомления | x=732, y=718, 456×354 |
| Launchpad | 8×4, иконки 120×120; начало x=256/y=124, шаг 184/196 |

Подложка SVG: `rgb(247,249,251)` с непрозрачностью 0.72, фоновые эффекты используют
blur 22 px. Вложенные светлые поверхности имеют непрозрачность 0.92.
CSS воспроизводит основные параметры; сложные градиенты границ приблизительные.
По решению пользователя от 2026-10-25 основной режим с прозрачностью и blur —
визуальная цель MVP обеих оболочек: [ADR-0011](../../adr/0011-mock-visual-target.md),
[правила сверки](../../rules/mock-parity.md). Непрозрачный режим остаётся вспомогательным
средством сравнения и не является эталоном приёмки.

## Известные отличия

- В меню Сбера четыре действия принятого MVP вместо пяти исходных: корпоративные
  настройки исключены по [правилу меню](../../rules/sber-menu.md).
- В меню питания пять согласованных действий; команды с обновлением исключены
  по решению пользователя в PANEL-012. SVG источника сохраняется без изменений.
- Корпоративный поиск исключён из MVP. В локальной выдаче нет исходной нижней
  кнопки корпоративного поиска; размер контейнера SVG сохранён.
- SVG списка уведомлений показывает счётчик 5 и только три карточки. В моке три
  демонстрационные записи и согласованный с ними счётчик 3; очистка удаляет их и закрывает контейнер с пустым состоянием строки.
- SVG светлые. Для сравнения тёмных Quick Settings/календаря используются PNG;
  тёмное оформление остальных новых окон — адаптация мока.
- Источник Launchpad содержит 32 приложения и три точки страниц. В моке одна
  заполненная страница; дополнительные приложения не выдумываются. Поиск «сбер»
  в Launchpad даёт семь приложений по PNG; локальная выдача Оськи — четыре по SVG.
- Разные PNG имеют разные размеры и состояния служб. При наложении они приводятся
  к общей сцене. Смена темы сохраняет настройки; демонстрационные состояния могут
  задавать значения из соответствующего кадра.
- Звуковые индикаторы остаются в галерее; поиск документов использует шесть
  демонстрационных записей. Системные интеграции не реализованы этим макетом.

## Проверки

Синтаксис `mock.js` проверен Node.js. Временная проверка Node VM с подставным DOM
прошла для 26 состояний и существования связанных SVG/PNG; поиска Launchpad,
локальной выдачи/пустого результата, очистки уведомлений, календарных границ,
Wi-Fi, Bluetooth, профилей и +N. Это не проверка браузерной отрисовки.

Оригинальные SVG растрированы офлайн и просмотрены; извлечённые аватар и значки
также просмотрены. Это проверяет источники/извлечение, но не CSS. Офлайн-рендер
SVG не воспроизводит `foreignObject` с фоновым blur.

Браузерная политика сеанса запрещает наблюдение `file:`-страниц. Снимки живого
HTML до/после, обе темы и клавиатурный обход остаются непроверенными. Эти критерии
сохраняются в [PANEL-011](../../tasks/PANEL-011.md); задача остаётся в работе.
