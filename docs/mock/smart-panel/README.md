# Smart Panel: интерактивный HTML-мок

Открыть `index.html` в браузере. Сборка, установка зависимостей и сервер не нужны.
Страница работает локально с относительными путями. При обновлении исходников
нужно перезагрузить уже открытую вкладку.

В правом верхнем углу находится кнопка «Мок · управление». Она открывает список
24 демонстрационных состояний, переключатели темы и поверхностей, масштаб 1:1
и режим наложения «Сверить со скриншотом». Ползунок оставляет слева HTML-мок,
справа — выбранный исходный PNG. Клавиша H скрывает/возвращает управление.

Основная страница содержит HTML-кнопки, поля ввода, регуляторы и календарь.
Launchpad фильтрует приложения при вводе, календарь переключает месяцы, формы
Wi-Fi/Bluetooth/питания сохраняют выбранные в моке значения. Esc закрывает
сначала дочерний уровень. Запуск приложения и действия сеанса демонстрационные.
Галерея всех 37 кадров сохранена отдельно в `references.html`.

## Источники и происхождение графики

ТЗ и оригинальные изображения: [`docs/sources/panel/`](../../sources/panel/).
Тексты требований и снимки не изменялись. Фон рабочего стола взят из
`applications-empty.png`; видимые иконки и аватар Оськи показаны CSS-фрагментами
исходных PNG, без генерации или подмены на emoji. Системные линейные значки
нарисованы SVG в `mock.js`; они приблизительные.

В режиме «Поверхности: по макету» воспроизводятся полупрозрачные подложки
исходного визуального материала. Режим «Непрозрачные» показывает направление
адаптации по ADR-0008/SHELL-001. Это инструменты обсуждения референса;
они не меняют принятые решения об оформлении рабочих оболочек.

### Наблюдения и ограничения

- Первоначальная стилизация с абстрактным CSS-фоном и emoji не соответствовала
  предоставленным изображениям. Последующая замена всего интерфейса галереей
  была решением агента, а не дополнительным требованием пользователя.
- В меню Сбера на исходном изображении пять иконок, включая корпоративные
  настройки. HTML-мок оставляет четыре пункта принятого MVP по
  [`sber-menu.md`](../../rules/sber-menu.md). Это намеренное отличие.
- Исходные PNG имеют разные размеры: основные сцены 1920×1080,
  календарь 1917×1080, быстрые настройки 1914–1920×1073–1075,
  индикаторы примерно 960×538. При наложении они приводятся к общей сцене;
  небольшие расхождения между самими кадрами не являются ошибкой CSS.
- В кадре `quick-settings-bt-not-found.png` переключатель выглядит выключенным.
  В моке сценарий назван «Bluetooth · отключён», чтобы не подменять отсутствие
  найденных устройств состоянием службы.
- Светлый и тёмный общие кадры Quick Settings различаются также состояниями
  Bluetooth и уведомлений. Смена темы в живом моке сохраняет значения настроек.
- В `launchpad-open.png` видны три точки страниц, но источник содержит только
  первую страницу из 32 приложений. В живой демонстрации одна доступная
  страница; дополнительные страницы не заполнены выдуманными приложениями.
- Счётчик +12 и раскрытый список на двух картинках не дают однозначной общей
  модели количества. В моке +N вычисляется из демонстрационной модели;
  неполная последняя строка допустима по FT_APPLICATIONS_12.
- Отдельные состояния звуковых индикаторов доступны в галерее. Системная
  интеграция, полнота уведомлений и весь набор FT не реализованы этим макетом.
- Фон содержит исходный статичный рабочий стол. Его нижние острова перекрыты
  живыми HTML-контролами. Мок не предназначен для замены произвольных обоев.

## Проверки

Синтаксис `mock.js` проверен Node.js. Временная проверка логики в Node VM
с подставным DOM прошла: загрузка всех 24 состояний, существование связанного
PNG, семь результатов «сбер», пустая выдача, календарная граница года и високосный
февраль, Wi-Fi, Bluetooth, выбор профиля, уведомление и раскрытие/закрытие +N.
Это проверка логики и разметки, не браузерной отрисовки.

Браузерная политика сеанса запрещает наблюдение `file:` страниц, в том числе
уже открытой пользователем вкладки. Локальные изображения просмотрены инструментом
чтения файлов, однако снимки до/после живого HTML, обе темы, реальная геометрия CSS
и клавиатурный обход в браузере остаются непроверенными. Эти пункты сохраняются
в [PANEL-011](../../tasks/PANEL-011.md); задача остаётся в работе.
