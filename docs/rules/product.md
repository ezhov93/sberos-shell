# Продуктовые ограничения

Источник: [бриф](../sources/brif_DE.odt), разделы 2–4; [презентация](../sources/SberOS_DE.pptx), слайды 8–11. Статус: ограничения концепции, не свидетельство готовности продукта.

## Обязательные границы инициативы

- Сохранить критичные пользовательские сценарии и совместимость с обязательными корпоративными приложениями; не ухудшать привычные способы работы.
- Использовать готовый композитор. Не разрабатывать собственный и не переписывать зрелые системные компоненты без необходимости.
- Поддерживать единую Wayland-сессию. XWayland допустим для необходимых X11-приложений; отдельная X11-сессия в целевую модель не входит.
- Устранить зависимость ключевого интерфейса от расширений GNOME Shell. Изолировать компоненты и предусмотреть восстановление без завершения сессии там, где это технически возможно; повысить диагностируемость.
- Предусмотреть единый API управления рабочим пространством, независимое развитие сценариев и оформления.
- AI-управление через MCP должно учитывать разрешения, безопасность и аудит. Неограниченный доступ к системе недопустим.
- Внедрять поэтапно после подтверждения качества и готовности основных сценариев.

## UX и интеграция

Презентация предлагает общий интерфейс действий для панели, поиска, горячих клавиш и AI: команды, состояния и события для окон, приложений, рабочих областей и контекстов. Поле AI-запроса — часть целевого видения; конкретный контракт пока не задан.

Согласовывать панели, уведомления, темы, системные формы и заголовки окон. Учитывать, что GTK/Qt-приложения могут рисовать заголовки самостоятельно: замена DE не гарантирует одинаковое оформление всех окон. Не терять встроенные меню и поиск приложений.

## Граница защищённой сессии

Карта сценариев различает экран входа и разблокировку. На разблокировке нельзя входить другим пользователем (`10-22`); доступные сеть, звук, яркость и средства доступности не должны раскрывать содержимое сессии. Уведомления при демонстрации экрана требуют проверки конфиденциальности (`05-18`, область `08`). Точные минимумы приведены в реестре.
