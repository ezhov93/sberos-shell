# Меню Сбер (PANEL-002)

Источник: [button-sber.md](../sources/panel/button-sber.md),
`FT_SMART_PANEL_SBER_BUTTON_1–8`, с отклонениями [ADR-0009](../adr/0009-smart-panel-scope.md).
Корпоративные настройки вне MVP; внутренним настройкам shell не назначается
контекстное меню внешнего приложения.

## Поведение

- Крайняя левая кнопка раскрывает вверх четыре иконки: настройки shell,
  системный терминал, питание/сессия, сворачивание. Нижняя кнопка находится
  на месте исходной кнопки Сбер; соседние зоны не сдвигаются.
- Настройки открывают собственное окно shell. Терминал выбирается существующим
  `Shell.defaultTerminal()`; закрытие меню не зависит от результата запуска.
- Питание раскрывается справа, основное меню остаётся открытым. Дочерний уровень
  следует SVG: пять текстовых строк без иконок — «Завершить сеанс»,
  «Перезагрузить», «Выключить», разделитель, «Заблокировать экран» и «Спящий
  режим». У строк выключения и блокировки показаны подсказки `Ctrl+Alt+Delete`
  и `Win+L`; они не меняют контракт системных сочетаний. Используются действия
  и подтверждения существующего PowerMenu. По уточнению пользователя строки
  «Перезагрузить с обновлением» и «Выключить с обновлением» из SVG в меню не
  включаются.
- ПКМ по терминалу или клавиша Menu при фокусе на нём открывает desktop actions
  приложения, затем закрепление/открепление. Закрепление сохраняет основной
  контейнер; ArcMenu отсутствует. Для терминала без найденного desktop ID
  обычный запуск остаётся доступным, контекстное меню не выдумывается.
- Esc и клик вне верхнего дочернего закрывают только его и поглощают клик.
  Без дочерних закрывается основное меню. Клик в дочернем контейнере не является
  внешним; повторная кнопка питания сначала закрывает дочерний уровень.
- Начальный фокус находится в контейнере, ни один пункт не выбран. Down/Tab
  начинают с первого, Up/Shift+Tab — с последнего, затем обход циклический.
  Enter без выбранного пункта ничего не запускает. Дочерние кнопки используют
  собственную навигацию; Esc возвращает фокус вызвавшему пункту только при
  клавиатурном открытии. При указательном открытии фокус пункта не создаётся.
- Общий вызов `Shell.toggleLauncher` / существующее действие KGlobalAccel
  открывает меню Сбер и повторно закрывает сразу все уровни. Bare Super/Alt+F1
  по-прежнему принадлежат оболочке только в режиме `--own-launcher-key`.
  Распознавание одиночного Super после отпускания и исключение сочетаний/повтора
  остаётся ответственностью существующей системной интеграции KGlobalAccel.
  Прямой запуск для разработки глобальные сочетания не захватывает.

## Мониторы и реализация

`Main` создаёт один SberMenu на сессию. Кнопка открывает его на своём экране;
клавиатура использует последний активный экран окна/панели, затем основной
доступный экран. При переносе сначала скрывается прежняя поверхность. Если
открыт дочерний уровень, первое нажатие кнопки на другом экране закрывает
только его, следующее переносит меню. Панель удерживается видимой во время меню.

Пока меню открыто, прозрачные SberMenuCatcher на остальных экранах поглощают
внешний клик и закрывают верхний уровень без активации окна под ним. Они не
запрашивают клавиатуру и скрываются вместе с меню. Изменение набора экранов
закрывает меню.

AppsModel получает desktop actions из KService и запускает их стандартным
KIO::ApplicationLauncherJob (добавлена зависимость KF6 KIOGui); команды из
desktop-файлов не разбираются вручную. Питание использует прежний PowerMenu
как контроллер, при закрытии дочернего уровня сбрасывается подтверждение/таймер.
Визуальная цель меню и его поверхности задаётся [правилами соответствия моку](mock-parity.md).

## Проверки

Сценарии: `02-02`, `04-07`, `09-24`, точки входа `10-01`, `10-05`, `10-07`, `10-09`.
Реальные блокировка/сон/завершение сессии в автоматических проверках запрещены:
PowerMenu должен иметь dryRun=true. Терминал и его desktop actions также не
запускать в тестах; изменения закреплений выполнять только во временной конфигурации.
Снимки обеих тем и результаты находятся в отчёте задачи. Ширина пока только 1920 px
по ADR-0008; аппаратные сочетания и реальные несколько мониторов отмечать отдельно
от внедрения событий QtTest и виртуальных экранов.

## Уточнение Plasma от 27.10.2026

По прямому решению пользователя для `plasma-theme/` исходная кнопка Сбера
остаётся внизу открытого меню; настройки, терминал и питание выдвигаются над ней.
Повторное нажатие сворачивает меню (при открытом питании сначала закрывается
дочерний уровень). Поверхность раскрывается вверх из кнопки и складывается
обратно; соседние острова и резервирование края экрана сохраняются.
Символ Сбера заменяет нижнюю стрелку сворачивания из исходного мока только
в Plasma. Сирка/Quickshell и исходный мок этим уточнением не меняются.
