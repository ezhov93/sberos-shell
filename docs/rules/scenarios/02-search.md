# 02. Поиск и запуск

Источник: [карта сценариев v1.1](../../sources/sbersosvg.svg), октябрь 2026. Сценариев: 14.

Приоритеты и формулировки сохранены из источника; это требования к проверке, а не подтверждение реализации. См. [правила применения](../README.md).

## 02-01 — Открыть обзор активностей

- **Приоритет:** P0.
- **Когда:** Нужно найти окно или приложение
- **Минимум:** Появился обзор окон и поиск.

## 02-02 — Найти приложение по названию

- **Приоритет:** P0.
- **Когда:** Нужно запустить известную программу
- **Минимум:** Приложение запущено. Сохранить единый поиск и порядок результатов.

## 02-03 — Найти приложение без знания названия

- **Приоритет:** P1.
- **Когда:** Не помню точное название
- **Минимум:** Найдена нужная программа.

## 02-04 — Запустить приложение из избранного

- **Приоритет:** P0.
- **Когда:** Приложение используется часто
- **Минимум:** Сохранить быстрый запуск из закреплённой зоны.

## 02-05 — Закрепить приложение в избранном

- **Приоритет:** P1.
- **Когда:** Часто пользуюсь программой
- **Минимум:** Значок появился в Dash. Сохранить DnD, уточнить альтернативный способ.

## 02-06 — Убрать приложение из избранного

- **Приоритет:** P2.
- **Когда:** Приложение больше не нужно постоянно
- **Минимум:** Панель избранного очищена. Сохранить управляемость списка закреплений.

## 02-07 — Вернуться в уже запущенное приложение

- **Приоритет:** P0.
- **Когда:** Программа уже открыта
- **Минимум:** Фокус на её окне. Сохранить работу и с приложением, и с конкретным окном.

## 02-08 — Открыть новое окно запущенного приложения

- **Приоритет:** P1.
- **Когда:** Нужен ещё один экземпляр окна
- **Минимум:** Открыто новое окно.

## 02-09 — Открыть приложение горячей клавишей

- **Приоритет:** P1.
- **Когда:** Нужна быстрая команда
- **Минимум:** Приложение открыто без навигации по меню. Сохранить клавиатурный запуск с привычными номерами.

## 02-10 — Запустить команду через Alt+F2

- **Приоритет:** P2.
- **Когда:** Нужно выполнить команду программы
- **Минимум:** Команда выполнена / приложение открыто.

## 02-11 — Искать файлы из общего поиска

- **Приоритет:** P1.
- **Когда:** Нужен документ, а не программа
- **Минимум:** Доступен переход к найденному документу. Сохранить локальный поиск; корпоративный источник отдельно.

## 02-12 — Найти корпоративный ресурс из системного поиска

- **Приоритет:** P0.
- **Когда:** Пользователь вводит запрос в общем поиске
- **Минимум:** Пользователь видит локальные и корпоративные результаты без переключения приложения.

## 02-13 — Видеть корпоративные результаты в конце выдачи

- **Приоритет:** P1.
- **Когда:** Общий поиск дал несколько типов результатов
- **Минимум:** Приоритет локальных результатов сохраняется, корпоративные остаются доступными.

## 02-14 — Запустить закреплённое приложение по номеру

- **Приоритет:** P0.
- **Когда:** Есть закреплённые приложения на панели
- **Минимум:** Открывается ожидаемое приложение, без конфликта с системными или прикладными клавишами.
