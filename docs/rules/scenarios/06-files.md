# 06. Файлы и документы

Источник: [карта сценариев v1.1](../../sources/sbersosvg.svg), октябрь 2026. Сценариев: 38.

Приоритеты и формулировки сохранены из источника; это требования к проверке, а не подтверждение реализации. См. [правила применения](../README.md).

## 06-01 — Открыть файловый менеджер

- **Приоритет:** P0.
- **Когда:** Нужны локальные документы
- **Минимум:** Файловый менеджер открыт.

## 06-02 — Перейти к известной папке

- **Приоритет:** P0.
- **Когда:** Ищу документ в стандартном расположении
- **Минимум:** Открыта нужная папка. Сохранить доступ как к обычному каталогу.

## 06-03 — Найти файл по имени

- **Приоритет:** P0.
- **Когда:** Не помню папку
- **Минимум:** Найден файл. Сохранить поиск и по имени, и по содержимому.

## 06-04 — Открыть документ

- **Приоритет:** P0.
- **Когда:** Нашёл файл
- **Минимум:** Документ открыт. Сохранить пункт «Открыть» и двойной щелчок с одним обработчиком MIME-типа.

## 06-05 — Выбрать другое приложение

- **Приоритет:** P1.
- **Когда:** Нужен другой редактор/просмотрщик
- **Минимум:** Открыт подходящий обработчик. Не смешивать разовое открытие другим приложением с изменением обработчика по умолчанию.

## 06-06 — Работать с несколькими папками

- **Приоритет:** P1.
- **Когда:** Перенос между каталогами
- **Минимум:** Папки одновременно доступны. Сохранить вкладки, несколько окон и запуск дополнительного окна с клавиатуры.

## 06-07 — Скопировать или переместить материалы

- **Приоритет:** P0.
- **Когда:** Отправить файлы в другой каталог
- **Минимум:** Данные находятся в назначенной папке. Сохранить не только горячие клавиши и DnD, но и копирование/перемещение через контекстное меню.

## 06-08 — Переименовать файл или папку

- **Приоритет:** P1.
- **Когда:** Нужно уточнить название
- **Минимум:** Файл или папка переименованы; переименование можно инициировать клавишей F2. Сохранить F2 и действие из контекстного меню.

## 06-09 — Удалить и восстановить файл

- **Приоритет:** P0.
- **Когда:** Удалил по ошибке
- **Минимум:** Файл восстановлен.

## 06-10 — Открыть файловый путь напрямую

- **Приоритет:** P1.
- **Когда:** Есть готовая ссылка на локальный каталог
- **Минимум:** Открыт указанный каталог.

## 06-11 — Подключить сетевую папку

- **Приоритет:** P0.
- **Когда:** Документ на сервере
- **Минимум:** Сетевая папка доступна. Сохранить доступ и понятную диагностику ошибок.

## 06-12 — Открыть съёмный носитель

- **Приоритет:** P1.
- **Когда:** Вставлена флешка
- **Минимум:** Доступны файлы без нарушения целостности.

## 06-13 — Выбрать файл в диалоге приложения

- **Приоритет:** P0.
- **Когда:** Прикрепить документ / скачать файл
- **Минимум:** В окне приложения пользователь может найти, выбрать и передать нужный файл (или несколько, если приложение разрешает), с доступной навигацией. Сохранить поиск, вставку пути, двойной щелчок по файлу, множественный выбор и сортировку для диалогов поддерживаемых приложений.

## 06-14 — Перенести файл между приложениями

- **Приоритет:** P0.
- **Когда:** Добавляю вложение / изображение
- **Минимум:** Файл принят приложением.

## 06-15 — Открыть облачное хранилище прямо в файловом менеджере

- **Приоритет:** P0.
- **Когда:** Нужно найти или сохранить файл в облачном хранилище
- **Минимум:** Пользователь работает с облачными файлами так же, как с обычной папкой.

## 06-16 — Сохранить файл в облачную папку из приложения

- **Приоритет:** P0.
- **Когда:** Приложение предлагает сохранить/экспортировать документ
- **Минимум:** Сохранение через системный диалог завершается и данные доступны в облачном каталоге.

## 06-17 — Выполнить полнотекстовый поиск внутри файлов

- **Приоритет:** P0.
- **Когда:** Нужный файл известен по содержимому, но не по имени
- **Минимум:** Находятся файлы по содержимому, а не только по названию.

## 06-18 — Открыть историю буфера обмена и вставить предыдущий элемент

- **Приоритет:** P0.
- **Когда:** Пользователь ранее скопировал несколько фрагментов
- **Минимум:** Можно выбрать и вставить ранее скопированный фрагмент без повторного поиска. История расширенного буфера должна работать и со снимками экрана; корректно сохранять/вставлять изображения и текст.

## 06-19 — Защитить чувствительные данные в истории буфера обмена

- **Приоритет:** P0.
- **Когда:** Расширенный буфер обмена используется в текущей SberOS
- **Минимум:** Пароли и другие чувствительные данные не оказываются доступны стороннему процессу или после выхода. Сохранить существующий сценарий при соблюдении корпоративных требований защиты информации; проверить текущую политику.

## 06-20 — Импортировать или прикрепить файл через диалог приложения

- **Приоритет:** P0.
- **Когда:** Браузер, почта или другое приложение просит выбрать локальный файл
- **Минимум:** Пользователь находит файл и передаёт его исходному приложению. Единые базовые операции файлового выбора для поддерживаемых приложений.

## 06-21 — Экспортировать или сохранить файл через диалог приложения

- **Приоритет:** P0.
- **Когда:** Скачать документ, экспортировать результат или сохранить «Как…»
- **Минимум:** Можно выбрать папку и имя файла, подтвердить сохранение и найти результат. Сохранить путь выбора директории, имя файла и предсказуемые подтверждения.

## 06-22 — Искать файлы внутри диалога импорта и экспорта

- **Приоритет:** P0.
- **Когда:** Файл/папка не найдены в текущем расположении
- **Минимум:** В доступном файловом диалоге пользователь может найти файл или нужную папку. Сохранить быстрый поиск в поддерживаемых диалогах.

## 06-23 — Вставить путь в файловом диалоге и перейти по нему

- **Приоритет:** P0.
- **Когда:** Путь к каталогу скопирован из чата/документа/файлового менеджера
- **Минимум:** После вставки полного пути и Enter открывается нужный каталог либо выбирается подходящий файл. Сохранить вставку пути как ключевой сценарий и проверять переход после Enter.

## 06-24 — Прикрепить файл двойным щелчком в файловом диалоге

- **Приоритет:** P0.
- **Когда:** Выбран нужный документ в окне импорта/прикрепления
- **Минимум:** Двойной щелчок по файлу подтверждает выбор и возвращает его приложению. Сохранить привычный паттерн двойного щелчка для вложений.

## 06-25 — Выбрать несколько файлов в диалоге прикрепления

- **Приоритет:** P0.
- **Когда:** Пользователь отправляет несколько документов одновременно
- **Минимум:** Можно выбрать несколько файлов, и все выбранные файлы передаются приложению. Сохранить множественный выбор в сценариях, где он разрешён.

## 06-26 — Сортировать файлы в диалоге выбора

- **Приоритет:** P0.
- **Когда:** В каталоге много файлов, нужно найти нужный по имени или атрибуту
- **Минимум:** Можно изменить порядок отображения файлов и выбрать нужный. Сохранить доступную сортировку диалогов импорт/экспорт.

## 06-27 — Показывать папки перед файлами в файловом менеджере

- **Приоритет:** P1.
- **Когда:** Просмотр смешанной папки с файлами и подпапками
- **Минимум:** При включённой опции папки отображаются до файлов. Сохранить настройку «папки перед файлами».

## 06-28 — Переключать файлы между значками и списком

- **Приоритет:** P1.
- **Когда:** Нужно просмотреть изображения либо подробные атрибуты документов
- **Минимум:** Можно переключать режимы отображения без потери выбранных объектов. Сохранить оба режима: миниатюры и список.

## 06-29 — Сортировать файлы в файловом менеджере по атрибутам

- **Приоритет:** P1.
- **Когда:** Нужно найти файл по дате, размеру, типу или имени
- **Минимум:** Доступна сортировка по поддерживаемым атрибутам, порядок понятен пользователю. Сохранить настройку сортировки по атрибутам.

## 06-30 — Открыть новое окно файлового менеджера горячей клавишей

- **Приоритет:** P1.
- **Когда:** Нужно работать с двумя каталогами параллельно
- **Минимум:** Новое окно файлового менеджера создаётся без мыши. Сохранить отдельную горячую клавишу нового окна.

## 06-31 — Сжать один или несколько файлов из контекстного меню

- **Приоритет:** P1.
- **Когда:** Нужно отправить набор файлов архивом
- **Минимум:** Контекстное меню предлагает сжатие и создаёт архив из выбранных объектов. Сохранить возможность «Сжать» из контекстного меню.

## 06-32 — Отправить один или несколько файлов в почту из контекстного меню

- **Приоритет:** P1.
- **Когда:** Нужно быстро переслать документ коллеге
- **Минимум:** Выбранные файлы передаются в создание письма как вложения. Сохранить контекстное действие отправки в почту.

## 06-33 — Печатать один или несколько файлов из контекстного меню

- **Приоритет:** P0.
- **Когда:** Нужно быстро распечатать рабочие документы
- **Минимум:** Для одного или нескольких поддерживаемых файлов запускается предсказуемая печать. Сохранить контекстную печать, в том числе пакетную.

## 06-34 — Копировать, вырезать, вставлять и перемещать файлы через контекстное меню

- **Приоритет:** P0.
- **Когда:** Пользователь управляет файлами через мышь вместо горячих клавиш
- **Минимум:** Все базовые операции доступны из контекстного меню без потери выбранных объектов. Сохранить действия «копировать», «вырезать», «вставить», «переместить».

## 06-35 — Выделять несколько файлов в файловом менеджере

- **Приоритет:** P0.
- **Когда:** Нужно отправить, сжать или распечатать набор документов
- **Минимум:** Ctrl/Shift и мышь выделяют нужный набор, а действия применяются ко всем файлам. Сохранить множественный выбор как основу пакетных файловых действий.

## 06-36 — Назначить приложение по умолчанию для типа файлов из контекстного меню

- **Приоритет:** P0.
- **Когда:** В меню «Открыть с помощью» выбран редактор, который удобнее использовать постоянно
- **Минимум:** Выбранная программа сохраняется как обработчик по умолчанию для соответствующего типа файлов. Сохранить изменение ассоциации непосредственно из сценария открытия файла.

## 06-37 — Создать ссылку на файл из контекстного меню

- **Приоритет:** P0.
- **Когда:** Нужна ссылка на существующий файл вместо его дублирования
- **Минимум:** Ссылка создаётся из контекстного меню и ведёт к исходному файлу. Сохранить возможность создавать ссылку без перехода в терминал.

## 06-38 — Скопировать файл прямо в выбранную папку из контекстного меню

- **Приоритет:** P0.
- **Когда:** Пользователь хочет скопировать файл в конкретный каталог, не открывая его отдельным окном
- **Минимум:** После выбора целевого каталога создаётся копия файла в этой папке, исходный файл остаётся на месте. Сохранить прямое копирование в произвольную доступную папку.
