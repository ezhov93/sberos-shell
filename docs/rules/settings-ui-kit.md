# Настройки оболочки и UI Kit

Источник: решение проекта от 2026-10-22, [ADR-0006](../adr/0006-settings-ui-kit.md). Это правила адаптации, дополняющие исходную спецификацию; формулировки и приоритеты реестра 270 сценариев не изменены.

## Область работы

Перевести собственное окно `shell/shell/qml/Settings.qml` на общий `ui-kit/`. Сохранить разделы внешнего вида, верхней панели, дока, поведения, рабочего стола и сведений об оболочке. Внешнее приложение KDE System Settings и его модули остаются отдельной интеграцией.

Основной справочник для использования библиотеки — [API-контракт UI Kit](../../ui-kit/docs/API.md).
Описанные свойства и события использовать по контракту; при обнаружении пробела
уточнять реализацию и дополнять документ в той же задаче. Известные ограничения
слайдера, полей ввода и выбора учитывать до замены элементов Sirca.

## Правила реализации

- Использовать компоненты и токены UI Kit для элементов управления, темы, типографики, размеров и состояний. Недостающие переиспользуемые элементы добавлять в UI Kit; предметную логику настроек оставлять в оболочке.
- Не терять существующие параметры, их значения, ограничения и сброс к значениям по умолчанию при замене элементов управления.
- Сохранять изменения в существующем формате конфигурации; применение должно происходить без перезапуска. Отложенные записи ползунков не должны теряться при смене раздела или закрытии окна.
- Сохранять открытие окна из лаунчера, быстрых настроек и ярлыка, а также переход на раздел через D-Bus.
- Обеспечить управление клавиатурой, видимый фокус и читаемость подписей, подсказок и значений в обеих темах.
- Подключение модулей и ресурсов UI Kit описать для сборки и запуска без необходимости устанавливать библиотеку в `/usr` для разработки.

## Критерии проверки

| Сценарии | Проверка миграции |
| --- | --- |
| `09-21` | Все разделы окна используют UI Kit; формы, меню и состояния соответствуют выбранной теме |
| `09-24` | Tab и Shift+Tab проходят по доступным элементам текущего раздела; фокус виден; элементы активируются клавиатурой |
| `09-02`, `09-19` | Открытое окно корректно меняет светлую и тёмную палитры вместе с оболочкой |
| `09-01` | Существующий выбор обоев сохраняется и применяется после замены интерфейса |

Дополнительно проверить открытие из всех существующих точек входа, запись и повторное чтение конфигурации, сброс параметров, крайние значения ползунков и отсутствие потери последнего изменения при закрытии. Сравнить перечень параметров до и после миграции.

Для визуальной проверки приложить скриншоты до и после, указать версию Qt, окружение рабочего стола и режим запуска. Проверка в `offscreen` не заменяет проверку ввода и интеграций в Wayland-сессии. Пропущенные проверки перечислять явно по [правилам приёмки](acceptance.md).

## Статус

Окно переведено на UI Kit. Изолированные проверки подтверждают переключение разделов
и тем, запись/сброс значений, ввод ползунками, фокус, выбор города и обоев
с подставными сервисами. [Отчёт и скриншоты](../../shell/shell/tests/settings/README.md)
фиксируют окружение и ограничения. Полное выполнение сценариев в Wayland ещё не подтверждено.
