# SberOS Smart Panel — технические требования (СТ)

> Источник истины: вики-страницы `confluence.sberbank.ru`, space `SBOS`, проект **Ussuri**.
> Этот документ — сводный (корневой) СТ по **Smart Panel** — новой нижней панели задач SberOS (GNOME Shell extension).
> Выгрузка/дата слепка: **2026-10-22**.

## Назначение и рамки

Smart Panel — новое GNOME Shell-расширение (временное название), нижняя панель задач SberOS
с задачами: меню «Сбер», панель приложений, «Оська» (поиск/уведомления), ситуативные индикаторы,
быстрые настройки и календарь, а также правила поставки и переключения с прежней панелью.

**В MVP не входят** (вне области реализации):
- AI-функции «Оськи»;
- удаление старой SberOS Panel;
- автоматическое включение Smart Panel всем пользователям;
- дублирование API корпоративного поиска.

## Статусы требований

> Статусы актуализирует аналитик, отвечающий за требования. Перед реализацией сверяй статус
> конкретного индекса `FT_...`/`UI_...`: **ЗАФИКСИРОВАНО** — реализуемо, **ДРАФТ** — может
> измениться, **ОТМЕНЕНО** — игнорируется.

- 🟦 **ДРАФТ** — на этапе разработки.
- 🟩 **ЗАФИКСИРОВАНО** — готово к реализации.
- 🟥 **ОТМЕНЕНО** — исключено, более не применяется.
- ⬜ **НОВОЕ/АДАПТИРОВАНО** — отдельные требования блоков могут нести пометку происхождения.

## Общие функциональные требования (поставка и переключение)

Все требования этой группы имеют статус **ДРАФТ**. Автор — Блинков А.С.

### FT_SBEROS_PANEL_USSURI_ROLLOUT_1 — Поставка в рамках пилотного сегмента
Дистрибутив SberOS предоставляет расширение «Smart Panel» **только согласованному пилотному сегменту MVP**. Состав сегмента и минимально поддерживаемое оборудование определяются утверждённым решением о развертывании.

### FT_SBEROS_PANEL_USSURI_ROLLOUT_2 — Существующая панель остаётся изначально активной
После установки обновления система оставляет существующую SberOS Panel включённой с сохранёнными настройками и **не заменяет** её новой панелью.

### FT_SBEROS_PANEL_USSURI_ROLLOUT_3 — Информирование через «Что нового»
Мастер «Что нового» сообщает подходящему пользователю о доступности новой панели и указывает путь её включения через раздел «Расширения».

### FT_SBEROS_PANEL_USSURI_ROLLOUT_4 — Управляемая пользователем активация
Система позволяет пользователю включать/отключать новое расширение через раздел «Расширения» без удаления какого-либо расширения.

### FT_SBEROS_PANEL_USSURI_ROLLOUT_5 — Безопасное переключение панелей
Система предотвращает появление перекрывающихся или дублирующихся элементов управления при переключении панелей, сохраняя возможность вернуться к старой панели.

### FT_SBEROS_PANEL_USSURI_ROLLOUT_6 — Сохранение закреплённых приложений при переключении
Система сохраняет пользовательский список закреплённых приложений и его порядок при переключении между старой и новой панелями.

### FT_SBEROS_PANEL_USSURI_ROLLOUT_7 — Режим развертывания по умолчанию изменяется только отдельным решением
Система сохраняет активацию нового расширения по выбору пользователя, пока отдельно утверждённое решение явно не изменит режим развертывания по умолчанию.

## Общие UI-требования

Все индексы — **ДРАФТ**. Автор — Блинков А.С. Макеты всех трёх групп, ссылка/версия Pixso — ТБР (Q-30).

### UI_SBEROS_PANEL_USSURI_1 — Главная панель Smart Panel
**Источник дизайна:** макеты всех трёх групп, Q-06/Q-30.

| Индекс | Элемент | Требование (действие) |
|---|---|---|
| `UI_SBEROS_PANEL_USSURI_1.1` | Подложка и пятизонная компоновка | Размещает меню «Сбер», приложения, «Оську», ситуативные и системные элементы **без взаимного перекрытия**. Условие отображения: расширение включено. |

### UI_SBEROS_PANEL_USSURI_7 — Переключение расширений и миграция
**Источник дизайна:** БТ-51–БТ-55; макет отсутствует; ТБР (Q-02/Q-03/Q-30).

| Индекс | Элемент | Требование (действие) |
|---|---|---|
| `UI_SBEROS_PANEL_USSURI_7.1` | Карточка «Что нового» | Информирует о новом расширении с панелью и даёт понятный путь к её активации. |
| `UI_SBEROS_PANEL_USSURI_7.2` | Действие «Попробовать Smart Panel» | Запускает переключение только по явному действию пользователя. |
| `UI_SBEROS_PANEL_USSURI_7.3` | Состояние активной панели | Однозначно показывает, какая панель активна; одновременное отображение двух панелей не допускается. |
| `UI_SBEROS_PANEL_USSURI_7.4` | Миграция закреплённых приложений | Переносит применимый список и порядок закрепов идемпотентно, с учётом обязательных приложений. |
| `UI_SBEROS_PANEL_USSURI_7.5` | Действие возврата к старой панели | Выключает Smart Panel и возвращает старую панель без потери информации о применённых закреплённых приложениях. |
| `UI_SBEROS_PANEL_USSURI_7.6` | Ошибка переключения/восстановление | Не оставляет пользователя без рабочей панели; точный recovery и текст ошибки — по Q-02. |
