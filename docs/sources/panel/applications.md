# Блок «Панель приложений»

> Часть СТ по **Smart Panel** (SberOS, проект Ussuri). Общий контекст — [SMART_PANEL.md](SMART_PANEL.md).
> Статусы всех требований здесь: **ДРАФТ** (на этапе разработки, могут измениться). Автор — Блинков А.С.

## Назначение блока
Закреплённые и запущенные приложения: запуск и активация окон, закрепление, изменение порядка,
предпросмотр окон, unread-бейджи, адаптивная компоновка с переполнением (+N), а также элемент
**Launchpad**.

## Термины и определения

| Термин | Определение |
|---|---|
| Smart Panel | Новое расширение панели (отдельно от существующей SberOS Panel). |
| Панель приложений | Отдельная область Smart Panel: закреплённые и запущенные приложения, их состояния и элемент доступа к переполнению. |
| Overflow +N | Кнопка-счётчик в конце компактной строки; N = число значков, скрытых за нехваткой места. |
| Закреплённое приложение | Отображается постоянно независимо от состояния (открыто/закрыто). |
| Незакреплённое приложение | Отображается только в открытом состоянии. |
| Компактное состояние | Однострочное представление области приложений в составе панели. |
| Развёрнутое состояние | Многострочное представление, раскрывается вверх и показывает значки, скрытые из компактной строки. |
| Индикатор окон | Отдельный от unread-бейджа и +N индикатор под значком; число горизонтальных маркеров = числу окон (1–4; при 5+ окнах — 4 маркера). |
| Unread-бейдж | Числовой бейдж СберЧата/Почты с переданным приложением числом непрочитанных. Получение значения — по интеграционному контракту приложения; здесь определяется только его отображение. |
| Launchpad | Служебный элемент панели приложений, открывающий экран просмотра/поиска приложений. Не приложение: нет окна, индикатора окон, предпросмотра, запуска нового экземпляра, закрепления/открепления. |

## Функциональные требования — Панель приложений

Все — **ДРАФТ**.

### FT_SMART_PANEL_APPLICATIONS_1 — Представление закреплённых и запущенных приложений
В компактном состоянии область — одна горизонтальная строка. Закреплённые видимы всегда; незакреплённые — только с открытыми окнами. Закреплённые располагаются перед незакреплёнными; перед непустой группой незакреплённых — разделитель. Все окна одного приложения — один значок. У приложения с окнами под значком — индикатор окон (1–4 маркера по числу окон; 4 при 5+). Индикатор окон не подменяется unread-бейджем или +N.
- ✎ При запуске незакреплённого — разделитель + значок; новый значок для второго окна не создаётся, индикатор обновляется; закрытие последнего окна прячет значок и (если группа пуста) разделитель; у закрытого закрепления значок остаётся без индикатора окон.

### FT_SMART_PANEL_APPLICATIONS_2 — Обязательные элементы области приложений
Три обязательных элемента в указанном порядке: **Launchpad, «Файлы», «Сбербраузер»**. Они не открепляются и не переставляются. Launchpad — первая позиция, при активации открывает экран Launchpad (по требованиям FT_SMART_PANEL_LAUNCHPAD). «Файлы» и «Сбербраузер» обрабатываются как закреплённые.

### FT_SMART_PANEL_APPLICATIONS_3 — Закрепление и открепление
ПКМ или удержание ЛКМ >1 сек открывают контекстное меню: сначала системные пункты приложения, затем «Прикрепить к панели приложений» (для незакреплённого) либо «Открепить» (для необязательного закреплённого). Для обязательных закрепов открепление не отображается. Пункт «Закрепить в ArcMenu» отсутствует. Для одного окна — «Завершить», для нескольких — «Завершить всё». После выбора действия или клика вне меню меню закрывается. Закрепление/открепление доступно и перетаскиванием (FT_4). На Launchpad правила контекстного меню не распространяются.
- ✎ Переходы групп, «Завершить»/«Завершить всё», обязательные закрепы, клик вне меню.

### FT_SMART_PANEL_APPLICATIONS_4 — Изменение порядка закреплённых приложений
Пользователь меняет порядок необязательных закрепов перетаскиванием; порядок сохраняется. Обязательные остаются в начале в порядке FT_2. Перенос незакреплённого в группу закреплений закрепляет его; недопустимая область сброса возвращает значок назад. Нумерация клавиатурных ускорителей обновляется после перестановки.
- ✎ Сверить сочетания Super+Цифра с новым порядком после перестановки; порядок восстанавливается после перезахода.

### FT_SMART_PANEL_APPLICATIONS_5 — Запуск закреплённого приложения
Активация закреплённого без окон запускает приложение; Super+Цифра — тот же запуск; Super+Shift+Цифра — новый экземпляр.

### FT_SMART_PANEL_APPLICATIONS_6 — Активация последнего активного окна
Первая активация значка запущенного приложения выводит на передний план последнее активное окно; повторные активации циклически переключают окна, после полного цикла следующая активация сворачивает их. Super+Цифра активирует существующее окно (не создаёт новый экземпляр). Средняя кнопка мыши запрашивает новое окно; при её неподдержке — обычная активация.

### FT_SMART_PANEL_APPLICATIONS_7 — Предпросмотр окон
Наведение на значок запущенного приложения показывает миниатюры и заголовки окон (для нескольких — от последнего активного к более ранним слева направо); предпросмотр позволяет активировать окно и содержит кнопку закрытия. Для закреплённого без окон вместо предпросмотра — подсказка с названием.

### FT_SMART_PANEL_APPLICATIONS_8 — Сохранение закреплённых приложений (миграция)
При переходе с прежней SberOS Panel состав пользовательских закрепов сохраняется без дубликатов. Первыми — обязательные: Launchpad, «Файлы», «Сбербраузер»; если «Файлы»/«Сбербраузер» отсутствовали — добавляются, если были — перемещаются на обязательные позиции без дубликатов. Остальные закрепы — после обязательных с сохранением взаимного порядка. Полное совпадение порядка со старой панелью не требуется. Состав и порядок сохраняются между сессиями и после обновлений ОС/расширений.
- ✎ Сценарии: добавление отсутствующих, перемещение с 5-й/7-й позиции на 2-ю/3-ю без дубликатов, повторный переход без дубликатов.

### FT_SMART_PANEL_APPLICATIONS_9 — Счётчики непрочитанных (Сберчат/Почта)
Значки СберЧата и Почты показывают отдельный числовой unread-бейдж с текущим переданным значением. Бейдж обновляется при изменении положительного значения и исчезает при нуле или отсутствии актуального значения. Отображается независимо от индикатора окон и +N.

### FT_SMART_PANEL_APPLICATIONS_10 — Управление unread-бейджами
Пользователь включает/отключает unread-бейджи СберЧата и Почты через предусмотренную системную настройку.

### FT_SMART_PANEL_APPLICATIONS_11 — Адаптивный размер элементов
Когда значки не помещаются при предпочтительном размере, область единообразно уменьшает их до минимального утверждённого размера (значки, отступы, индикаторы — согласованно, без наложения/обрезки). Если после уменьшения все помещаются, +N не появляется. Точные размеры/пороги — по дизайн-макету: прежде чем показывать +N, иконки должны уменьшиться с 40px до 32px, и только после переполнения отображается +N.

### FT_SMART_PANEL_APPLICATIONS_12 — Доступ к переполнению
Когда после минимального размера значки не помещаются, область сохраняет в компактной строке максимум значков и показывает после них кнопку +N. В первую очередь видимы закреплённые (в сохранённом порядке), затем — незакреплённые запущенные (в порядке появления). N = число скрытых значков, актуализируется при изменении состава, исчезает без переполнения. Клик по +N разворачивает область вертикально вверх; показываются все значки слева направо по строкам, неполная последняя строка — от левой границы. В развёрнутом состоянии +N не отображается. Если строки не помещаются в рабочую область монитора, контейнер ограничивается её границами и даёт вертикальную прокрутку.

### FT_SMART_PANEL_APPLICATIONS_13 — Сворачивание развёрнутой области
Esc или клик вне развёрнутой области сворачивает её до компактной строки без запуска приложений. Если открыты контекстное меню или предпросмотр, первое Esc/клик закрывают только их; следующее закрытие сворачивает область. Сворачивание не закрывает приложения/окна и не меняет закрепления/порядок. При сохранении переполнения +N пересчитывается. После закрытия клавиатурой фокус возвращается на кнопку +N.

### FT_SMART_PANEL_APPLICATIONS_14 — Эталонные состояния адаптивной компоновки
Для референсных ширин **1280, 1440, 1920** область сохраняет доступ к приложениям и воспроизводит последовательность: компактная строка → единообразное уменьшение → +N → разворачивание вверх в несколько строк → неполная последняя строка. Размеры/отступы/цвета — по утверждённому дизайн-макету.

### FT_SMART_PANEL_APPLICATIONS_15 — Работа на нескольких мониторах
На нескольких мониторах компактное/уменьшенное/переполненное состояния рассчитываются отдельно для доступной ширины каждого монитора. +N разворачивает область на том же мониторе (не переносится на основной/иной). Состояние области каждого монитора независимо: раскрытие/сворачивание на одном мониторе не меняет состояние на других.

## Функциональные требования — Launchpad

Все — **ДРАФТ**.

### FT_SMART_PANEL_LAUNCHPAD_1 — Открытие и закрытие
Активация значка Launchpad открывает экран поверх рабочего стола; пока экран открыт, Smart Panel и значок Launchpad не отображаются. Esc или клик по свободному фону закрывают без выбора. Выбор приложения в сетке/поиске передаёт запрос на запуск и сразу закрывает Launchpad независимо от результата. Запуск и ошибки приложения — вне зоны Smart Panel.

### FT_SMART_PANEL_LAUNCHPAD_2 — Состав экрана
Сетка доступных приложений (иконки + названия), индикатор страниц и поле поиска Оськи по центру нижней части. Верхний блок выбора рабочих столов и стандартное поле поиска GNOME Overview не отображаются.

### FT_SMART_PANEL_LAUNCHPAD_3 — Вместимость и навигация по страницам
≤8 значков в ряду, ≤4 рядов (не более **32** на странице). При меньшем пространстве количество на странице уменьшается; не поместившиеся — на следующих страницах. Индикатор показывает число страниц и выделяет текущую; точки выбирают страницу. Навигация указателем и клавиатурой — по штатному поведению списка приложений GNOME Shell в составе SberOS.

### FT_SMART_PANEL_LAUNCHPAD_4 — Поиск приложений
После открытия поле Оськи готово к вводу без клика. Поиск — только по названиям приложений; совпадения обновляются начиная с первого символа, без минимальной длины и ожидания паузы. В режиме Launchpad результаты по документам и кнопка корпоративного поиска не отображаются. Запрос остаётся видимым и редактируемым.

### FT_SMART_PANEL_LAUNCHPAD_5 — Пустая выдача и уведомления
При отсутствии совпадений вместо значков — «Ничего не найдено» (запрос остаётся). Очистка запроса восстанавливает полную сетку. Уведомление во время поиска отображается над полем Оськи и не изменяет запрос/фокус/результаты; состав/очередь/время — по требованиям к Оське.

### FT_SMART_PANEL_LAUNCHPAD_6 — Несколько мониторов
В сессии — не более одного экземпляра Launchpad. Активация значка открывает экран на мониторе значка; вызов с клавиатуры — на активном в момент вызова мониторе. На остальных мониторах Launchpad одновременно не открывается.
