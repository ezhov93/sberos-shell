# Блок «Оська»: состояния, поиск и уведомления

> Часть СТ по **Smart Panel** (SberOS, проект Ussuri). Общий контекст — [SMART_PANEL.md](SMART_PANEL.md).
> Статусы всех требований: **ДРАФТ**. Авторы — Блинков А.С. (состояния/поиск), Харитонова А.С. (уведомления).

## Назначение блока
Центральная область «Оська»: состояния и локальный поиск, переход в корпоративный поиск,
системные сообщения, список уведомлений (стопка → развёрнутый список).

## Термины и определения

| Термин | Определение |
|---|---|
| Оська | Центральная область Smart Panel: состояния панели, системные сообщения, поле локального поиска и точка перехода в корпоративный поиск. |
| Исходное состояние Оськи | Без активного ввода и системного сообщения: аватар Оськи + текст готовности к поиску + индикатор текущей раскладки. |
| Системное сообщение Оськи | Временное сообщение о поддерживаемом системном событии, автоматически показывается в строке вместо неактивного содержимого. Не карточка списка уведомлений. |
| Очередь системных сообщений | Последовательность ожидающих показа сообщений; показываются по одному, активный поиск их не прерывает. |
| Список уведомлений | Контейнер над «Оськой», открывается по аватару с колокольчиком; карточки уведомлений в виде свёрнутой стопки либо развёрнутого списка. |
| Счётчик уведомлений (N) | Число у заголовка «Уведомления», актуализируется при удалении карточек. Семантика (все/только непрочитанные) определяется источником, здесь не переопределяется. На аватаре числовой счётчик не отображается. |
| Локальный поиск | Поиск по локальным категориям «Приложения» и «Документы». Алгоритм индексации/ранжирования/состав источников здесь не определяются. |
| Корпоративный поиск | Отдельный от Smart Panel интерфейс, открывается в браузере с передачей текущего запроса; регулируется собственной СТ. |

## Функциональные требования — Состояния и поиск

Все — **ДРАФТ**.

### FT_SMART_PANEL_OSKA_1 — Положение и состав
Оська — в центральной области Smart Panel и сохраняет центральное положение при изменении содержимого соседних областей. В исходном состоянии: аватар, текст готовности к поиску, индикатор раскладки.

### FT_SMART_PANEL_OSKA_2 — Модель состояний
Поддерживаются: исходное состояние, приветствие после входа, индикация смены раскладки, системное сообщение, ввод запроса, локальная выдача, пустое состояние списка уведомлений. Активный ввод и локальная выдача имеют приоритет над автопоказом системных сообщений; поступившие тогда сообщения обрабатываются по FT_SMART_PANEL_NOTIFICATIONS_1. После временного состояния Оська переходит к следующему ожидающему сообщению либо возвращается в исходное состояние.

### FT_SMART_PANEL_OSKA_3 — Локализация приветствия, раскладки и системных сообщений
Приветствие и индикатор раскладки обновляются при переключении между поддерживаемыми раскладками: **русская, английская, китайская, хинди**.

### FT_SMART_PANEL_OSKA_4 — Активация локального поиска и ввод запроса
Начало ввода переводит Оську из исходного состояния в локальный поиск. Запрос остаётся видимым и редактируемым; обновление выдачи не очищает запрос и не сворачивает Оську.

### FT_SMART_PANEL_OSKA_5 — Отображение локальных результатов
Результаты в разделах «Приложения» и «Документы», актуализируются по мере ввода. Контейнер результатов имеет ограниченную высоту; при переполнении — вертикальная прокрутка. Кнопка «Искать в корпоративном поиске» закреплена внизу контейнера и остаётся видимой при прокрутке.

### FT_SMART_PANEL_OSKA_6 — Переход в корпоративный поиск
Активация кнопки передаёт текущий запрос в корпоративный поиск, открывает его в браузере и возвращает Оську в исходное состояние.
**Граница ответственности Smart Panel:** поле ввода Оськи, показ локальных результатов, точка перехода, передача запроса, возврат в исходное состояние. Правила корпоративного поиска, состав/ранжирование выдачи, интеграция, безопасность, URL, отображение и действия с результатами — вне зоны Smart Panel (см. [СТ]-v.2 «Корпоративный поиск в SberOS»).

### FT_SMART_PANEL_OSKA_7 — Совместимость с системными и стандартными сочетаниями
Поле ввода поддерживает стандартные копирование/вставку текста. Оська, локальная выдача и контейнер уведомлений не перехватывают и не блокируют системное сочетание **Sber (Super)+L** (блокировка сеанса).

## Функциональные требования — Уведомления

Все — **ДРАФТ**.

### FT_SMART_PANEL_NOTIFICATIONS_1 — Приветственное уведомление при входе
После первого входа в сессию — один раз показать приветствие в «Оське». Перезапуск Smart Panel, повторное включение расширения, блокировка/разблокировка экрана **не** повторяют приветствие в той же сессии. Приветствие **не** попадает в очередь и стопку.

### FT_SMART_PANEL_NOTIFICATIONS_2 — Получение и фильтрация системных уведомлений
Smart Panel получает уведомления от системного компонента через существующий интерфейс. В «Оську» допускаются **только** события:
- подключение/отключение Wi-Fi;
- подключение/отключение VPN;
- низкий заряд;
- подключение зарядки;
- загруженное обновление ОС;
- окончание срока пароля.

Уведомления о смене раскладки обрабатываются только по FT_SMART_PANEL_OSKA_3 и **не** добавляются в очередь. Компонент фильтрует по критичности/источнику/настройкам; Smart Panel принимает только разрешённые из списка. Остальные — не попадают в показ/очередь/стопку.

### FT_SMART_PANEL_NOTIFICATIONS_3 — Критичность уведомлений
Компонент передаёт уровень критичности **low/normal/critical** (Desktop Notifications). Smart Panel использует уровень только для решения о допуске в «Оську»/стопку и **не** переопределяет его. Показываются уровни **normal и critical** из перечня FT_2; **low** не показывается и не попадает в очередь/стопку. Таймаут critical задаётся компонентом — Smart Panel не сокращает его.

### FT_SMART_PANEL_NOTIFICATIONS_4 — Добавление в очередь
Принятые уведомления добавляются в очередь по **FIFO**. Повторное уведомление с тем же ID не создаёт вторую запись; при замене источник обновляет существующую. Критичность не меняет порядок в очереди.

### FT_SMART_PANEL_NOTIFICATIONS_5 — Показ при отсутствии поиска
Если нет активного поиска и область результатов закрыта, текущее уведомление временно заменяет подсказку и поле ввода. По завершении времени показа уходит в стопку (FT_OSKA_STACK, см. FT_7 ниже), Smart Panel показывает следующее из очереди или возвращается к состоянию по умолчанию.

### FT_SMART_PANEL_NOTIFICATIONS_6 — Показ во время ввода и поиска
При вводе запроса или открытой выдаче уведомление не меняет запрос/фокус/результаты; в режиме поиска показывается **над выдачей**, остальные остаются в очереди. Если поиск запускается во время показа уведомления — оно смещается из строки наверх **без** повторного добавления в очередь и **без** перезапуска таймера.

### FT_SMART_PANEL_NOTIFICATIONS_7 — Перемещение в стопку
Уведомление отображается заданное время, затем перемещается в стопку. Перемещение не выполняет действие уведомления и не меняет его состояние во внешнем источнике без требования контракта. После перемещения — следующее из очереди или состояние по умолчанию. *(Соответствует FT_SMART_PANEL_OSKA_STACK_1 из источника.)*

### FT_SMART_PANEL_NOTIFICATIONS_8 — Анимация перехода
Смена уведомлений сопровождается анимацией, которая не меняет порядок очереди, не блокирует приём новых и не показывает два уведомления одновременно. При отключённых системных анимациях — простая смена текста.

### FT_SMART_PANEL_NOTIFICATIONS_9 — Язык и отображение текста
Все уведомления, кроме смены раскладки, — на языке текущей локализации. О смене раскладки — на языке новой раскладки. При переполнении строки текст сокращается по макету; полный — в карточке стопки и через средства доступности. Smart Panel **не** выполняет разметку, команды и ссылки из текста уведомления.

### FT_SMART_PANEL_NOTIFICATIONS_10 — Индикация на аватаре
Если в стопке есть карточка — аватар показывает колокольчик **без числа**. Пустая стопка — колокольчика нет. Первая карточка включает, удаление последней выключает.

### FT_SMART_PANEL_NOTIFICATIONS_11 — Значение N в заголовке
Заголовок «Уведомления N», N = число карточек. Удаление уменьшает N на 1, очистка — до 0. Открытие/сворачивание/разворачивание N не меняют.

### FT_SMART_PANEL_NOTIFICATIONS_12 — Открытие свёрнутой стопки
ЛКМ по аватару с колокольчиком открывает свёрнутую стопку: заголовок «Уведомления N», кнопка «Очистить», верхняя карточка (иконка, заголовок, текст, время) и слои остальных. Повторный клик по аватару, Esc или клик вне закрывают без изменения состава и N.

### FT_SMART_PANEL_NOTIFICATIONS_13 — Разворачивание списка
ЛКМ по верхней карточке разворачивает список. Одновременно видно **не более трёх** карточек, остальные — вертикальная прокрутка. Порядок — как у компонента; по умолчанию новые выше. Разворот не уменьшает N, не удаляет карточки и не открывает приложения-источники.

### FT_SMART_PANEL_NOTIFICATIONS_14 — Удаление одной карточки
При наведении время справа заменяется кнопкой закрытия; при уводе курсора — возвращается. Клик по закрытию удаляет карточку и уменьшает N на 1; следующая карточка занимает её место, состояние контейнера (свёрнутое/развёрнутое) сохраняется. Удалённая карточка не возвращается после закрытия/открытия стопки, синхронизации или перезапуска, если источник не прислал новую с новым ID.

### FT_SMART_PANEL_NOTIFICATIONS_15 — Очистка стопки и пустое состояние
«Очистить» удаляет все карточки, N = 0. После очистки/удаления последней карточки контейнер закрывается, колокольчик убирается, в строке временно «Новых уведомлений пока нет», затем — состояние по умолчанию. Очистка **не** удаляет уведомления, ожидающие показа в очереди (если иное не оговорено), и **не** меняет состояние «прочитано»/не удаляет во внешних источниках без отдельного контракта.

### FT_SMART_PANEL_NOTIFICATIONS_16 — Общность состояния между панелями
В сессии текущее уведомление, очередь, стопка, N и колокольчик общие для всех экземпляров Smart Panel на всех мониторах. Открытие контейнера на любом мониторе показывает один список и одно N. Изменения на одном мониторе синхронизируются на остальных.

### FT_SMART_PANEL_NOTIFICATIONS_17 — Восстановление состояния после сбоя
При запуске, повторном включении или восстановлении после сбоя Smart Panel запрашивает у компонента актуальное состояние и восстанавливает очередь, стопку, N и колокольчик без дубликатов. Закрытые/отозванные/заменённые во время недоступности уведомления удаляются или обновляются во всех представлениях. Недоступность компонента **не** блокирует поиск, индикатор раскладки и другие области панели; после восстановления связи — повторная синхронизация.
- ✎ Сценарии: перезапуск восстанавливает состояние без дубликатов; отозванное уведомление отсутствует во всех представлениях; заменённое показано в обновлённом виде без лишней карточки; при недоступности компонента остальные области работают; после восстановления N синхронизируется.

Все индексы — **ДРАФТ**. Скринов в блоке нет (только Pixso-макеты, см. SMART_PANEL.md). Основные группы макетов: «Все состояния и уведомления Оськи»; «Аркменю. Ланчпад. Поиск в Оське» (только кадры локального поиска и перехода в корпоративный поиск); «Сценарий списка уведомлений в оське». Макеты корпоративного поиска после открытия браузера — иллюстрация точки перехода, UI Smart Panel не задают.

## ⚠️ Оговорки блока (из источника)

1. **Несогласованная нотация индексов в первичном источнике.** Функциональные требования уведомлений нумеруются как `FT_SMART_PANEL_NOTIFICATIONS_1..17`, но на UI-ссылки ссылаются на ряд `FT_SMART_PANEL_OSKA_NOTIFICATIONS_1..6`. В этом документе сохранены индексы так, как они идут в теле требований (`FT_SMART_PANEL_NOTIFICATIONS_*`); при реализации сверяться с первичным источником по конкретному индексу.
2. **Не определено и требует отдельного согласования** (из картинок не выводить): действие клика по карточке развёрнутого списка; закрытие контейнера по Esc/клику вне его; клавиатурная навигация; правила мультимониторного отображения; сортировка; семантика прочитанности.
3. Индексы `FT_SMART_PANEL_OSKA_STACK_1` и `FT_SMART_PANEL_OSKA_NOTIFICATIONS_3/4/5/6`, на которые есть ссылки, относятся к требованиям перемещения в стопку и работе списка (отражены выше как FT_7, FT_12–FT_15).
