## Цель и границы

Добавить в Sirca собственное отображение и управление содержимым XDG-папки Desktop
для режима без plasmashell. Переносить поведение и продуктовые решения DeskCenter,
а не Quickshell-специфичные зависимости. NextKDE остаётся неизменяемым эталоном.
Sirca продолжает использовать Qt/KIO/KWin и существующие поверхности оболочки.

Этапы: модель файлов и запуск; раскладка и значки; сортировка, размер/интервалы и
действия над файлами; выводы и восстановление после hotplug; запуск в обеих темах.
В штатном режиме с plasmashell значки остаются под управлением Plasma, чтобы не
создавать второй Folder View.

## Критерии готовности

- [ ] Sirca отображает содержимое XDG Desktop и открывает файлы, папки и desktop-файлы приложений.
- [ ] Из контекстного меню Launchpad можно создать desktop-файл приложения на рабочем столе.
- [ ] Значки можно выбирать и переставлять с привязкой к сетке; раскладка сохраняется.
- [ ] Контекстное меню поддерживает сортировку по имени/типу, выбор размера и плотности, создание папки, переименование и перемещение в корзину.
- [ ] Каждый элемент отображается ровно на одном выходе; новые ярлыки размещаются на DP-7 (или основном экране, если DP-7 отключён), перетаскивание между мониторами сохраняет уникальное размещение, порядок и доступность при отключении монитора.
- [ ] Рабочий стол готов к первому кадру без поэтапного появления обоев и значков.
- [ ] Sirca: сборка и применимые изолированные проверки; Wayland-проверка и снимки тёмной/светлой тем записаны либо явно ограничены средой.
- [x] NextKDE: не входит в область; используется только как референс, влияние подтверждено чтением исходников и документации.

## Неясности и ограничения

Существующие файлы в XDG Desktop остаются источником содержимого. По уточнению
пользователя 2026-10-23 новые ярлыки размещаются на DP-7, а существующие можно
перетаскивать между любыми подключёнными мониторами; одновременно один ярлык
отображается только на одном выходе. Стратегия совместимости
с форматами сохранения позиций Plasma не установлена; позиции Sirca хранятся отдельно,
если не появится подтверждённый общий формат. NextKDE поддерживает назначение значков
нескольким мониторам; Sirca хранит владельца каждого ярлыка отдельно и разрешает
перенос между экранами.
В текущем этапе ещё отсутствуют перенос файлов drag-and-drop из других приложений,
групповое выделение, clipboard-копирование/вставка и полноценная клавиатурная навигация.

## Следующий шаг

Проверить поведение на Wayland с отдельной тестовой папкой Desktop, обе темы,
перетаскивание между мониторами, отключение выхода DP-7 и работу операций. После этого добавить внешнее
перетаскивание, групповое выделение, буфер обмена и навигацию клавиатурой.

## Проверки и коммиты

`cmake --build build -j 4` из `shell/shell/` прошла после изменения маршрутизации
между мониторами. Изолированный Qt/QML запуск ранее загрузил `DesktopIcons` и
Launchpad; временная XDG-папка Desktop прочиталась с тестовыми папкой, текстовым
файлом и `.desktop`-файлом без QML-ошибок. Перетаскивание между мониторами и
восстановление после отключения DP-7 требуют проверки в Wayland. 2026-10-23
обновлённый бинарник проверен в активном пользовательском сервисе на DP-7
(2560×1440) и DP-6 (портретный 1080×1920): пользователь перенёс временный файл
DP-7 → DP-6, он появился на целевом экране без дубликата. Файл удалён; проверка
переноса обратно и hotplug остаётся впереди. Резервная копия предыдущего бинарника:
`/tmp/sirca-shell.pre-dp7-drag-20261023`.
`sirca-shell --check` в sandbox без Wayland/XCB display не запустился; повтор с
`QT_QPA_PLATFORM=offscreen` завершился по таймауту 25 секунд, и не считается
пройденной проверкой. Визуальная проверка, Wayland-поведение, обе темы, операции
над реальными файлами и смена основного экрана не проверены. Коммитов по задаче нет.
