## Цель и границы

Развести назначение документов: README — навигация и устойчивый контекст; ADR — решения; rules — действующие требования и проверка; карточки задач — статус, доказательства и следующий шаг. Удалять только повторные пересказы, сохраняя принятые решения, источники и историю, нужную для понимания причин.

Не менять продуктовые требования и код. Каталог `refs/` не редактировать.
