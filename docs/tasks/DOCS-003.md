## Цель и границы

Связать пользовательские экраны из SVG в интерактивном браузерном мокапе. Изменения относятся только к `docs/mock/login/` и навигации документации; оболочки, службы и реальные учётные данные не затрагиваются.

## Критерии готовности

- [x] Выбор пользователя ведёт к экрану пароля, успешный демонстрационный вход — к приветствию и рабочему столу.
- [x] С рабочего стола можно открыть экран блокировки и вернуться в ту же сессию.
- [x] Ввод пароля явно обозначен как локальная демонстрация без проверки, сохранения и отправки значения.
- [x] Мок связан со страницей документации и исходными макетами.
- [ ] Живой браузерный просмотр на обычном и узком размере экрана.

## Проверки и результат

Переходы реализованы в `docs/mock/login/`, а ссылки добавлены в README документации и источников. Живой предпросмотр не выполнен: браузерная политика запрещает открытие локальных `file:` URL; это ограничение не обходилось.
