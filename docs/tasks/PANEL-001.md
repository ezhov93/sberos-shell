## Цель и границы

Собрать пятизонную компоновку в собственной оболочке на Qt/QML с общим UI Kit. Системную интеграцию
адаптировать по решениям PANEL-000; не переносить GNOME API и механизм расширений автоматически.
Применимы [ADR-0008](../adr/0008-unified-bottom-panel.md),
[правила панели](../rules/unified-panel.md) и [контракт UI Kit](../../ui-kit/docs/API.md).

## Критерии готовности

- [ ] Зоны расположены в порядке: Сбер, приложения, Оська, ситуативные индикаторы, быстрые настройки и календарь.
- [ ] Оська сохраняет центр экрана, изменения индикаторов не сдвигают соседние зоны; наложений нет на ширинах 1280, 1440 и 1920.
- [ ] Оформление отдельных блоков сверено с макетами в двух темах; поведение выбранных экранов и резервирование нижнего края проверены в Wayland.

## Неясности и ограничения

Точные размеры, отступы, ширины зон и поведение при нехватке места требуют фиксации. По [SHELL-001](SHELL-001.md) использовать цвета UI Kit и непрозрачные поверхности без фонового blur; прозрачность макетов не воспроизводить. Существующая сплошная панель не является завершением этой задачи.
