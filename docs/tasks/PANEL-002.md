## Цель и границы

Реализовать меню Сбер в собственной оболочке на Qt/QML с общим UI Kit. Системную интеграцию
адаптировать по решениям PANEL-000; не переносить GNOME API и механизм расширений автоматически.
Применимы [ADR-0008](../adr/0008-unified-bottom-panel.md),
[правила панели](../rules/unified-panel.md) и [контракт UI Kit](../../ui-kit/docs/API.md).

## Критерии готовности

- [ ] Крайняя левая кнопка раскрывает вверх четыре иконки MVP в порядке: настройки shell, терминал, питание/сессия, сворачивание; питание открывает дочернее меню справа.
- [ ] Esc и клик вне закрывают верхний уровень без активации элемента под ним; одиночный Super переключает меню после отпускания.
- [ ] Проверены контекстные меню, закрепление, клавиатурный фокус и перенос единственного меню между мониторами.

## Неясности и ограничения

Решение пользователя от 2026-10-22: корпоративные настройки вне MVP, их пункт не показывать. Пункт настроек открывает собственные настройки shell, не KDE systemsettings. Поэтому вместо пяти иконок источника в MVP четыре. Терминал запускать через системную точку входа без зависимости от GNOME Terminal; конкретный способ определить при реализации. Контекстное меню приложения не навязывать внутренней точке входа настроек shell; её поведение и фокус проверить отдельно по таблице адаптации. Состав power-menu регулируется внешним документом, которого здесь нет.
