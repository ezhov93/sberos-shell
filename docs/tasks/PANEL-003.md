## Цель и границы

Адаптировать приложения и переполнение в собственной оболочке на Qt/QML с общим UI Kit. Системную интеграцию
адаптировать по решениям PANEL-000; не переносить GNOME API и механизм расширений автоматически.
Применимы [ADR-0008](../adr/0008-unified-bottom-panel.md),
[правила панели](../rules/unified-panel.md) и [контракт UI Kit](../../ui-kit/docs/API.md).

## Критерии готовности

- [ ] Launchpad, Файлы и Сбербраузер занимают обязательные позиции; остальные закрепления и порядок сохраняются без дубликатов.
- [ ] Реализована последовательность 40 px → 32 px → +N → многострочное раскрытие вверх с независимым расчётом на каждом мониторе.
- [ ] Проверены группировка, маркеры 1–4 окон, активация и цикл окон, предпросмотр, DnD, контекстное меню и возврат фокуса.
- [ ] Unread-бейджи отделены от маркеров окон и +N; доступны настройка и обработка отсутствующего значения по согласованному контракту.

## Неясности и ограничения
