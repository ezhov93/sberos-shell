## Цель и границы

Реализовать Оську и поиск в собственной оболочке на Qt/QML с общим UI Kit. Системную интеграцию
адаптировать по решениям PANEL-000; не переносить GNOME API и механизм расширений автоматически.
Применимы [ADR-0008](../adr/0008-unified-bottom-panel.md),
[правила панели](../rules/unified-panel.md) и [контракт UI Kit](../../ui-kit/docs/API.md).

## Критерии готовности

- [ ] Центральное поле объединяет аватар, подсказку и раскладку; реализованы явно определённые состояния и приоритет активного ввода.
- [ ] Выдача приложений и документов обновляется по вводу, прокручивается отдельно от закреплённой кнопки корпоративного поиска.
- [ ] Согласованный переход в корпоративный поиск передаёт запрос и возвращает исходное состояние; копирование/вставка и Super+L работают.
- [ ] Проверены поддерживаемые раскладки, обе темы, фокус и сохранение запроса при системных сообщениях.

## Неясности и ограничения

Черновик. Нужны источники локального поиска и внешний контракт корпоративного поиска (URL, передача запроса, безопасность). AI-функции вне MVP.
