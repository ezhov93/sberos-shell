## Цель и границы

Реализовать уведомления Оськи в собственной оболочке на Qt/QML с общим UI Kit. Системную интеграцию
адаптировать по решениям PANEL-000; не переносить GNOME API и механизм расширений автоматически.
Применимы [ADR-0008](../adr/0008-unified-bottom-panel.md),
[правила панели](../rules/unified-panel.md) и [контракт UI Kit](../../ui-kit/docs/API.md).

## Критерии готовности

- [ ] Уведомления фильтруются по перечню и критичности, очередь FIFO не дублирует ID и корректно обрабатывает замену.
- [ ] Сообщение переходит в стопку; поиск сохраняет запрос, фокус и таймер сообщения; приветствие показывается один раз за сессию.
- [ ] Аватар показывает колокольчик без числа; стопка и список с максимум тремя видимыми карточками поддерживают удаление, N и очистку.
- [ ] Состояние общее между мониторами, восстанавливается после недоступности источника без возврата удалённых карточек; отключение показа не подтягивает пропущенные.

### Готовность по проектам

- Sirca [ ] Очередь, стек, поиск и управление уведомлениями реализованы и проверены в Sirca по основной карточке.
- NextKDE [ ] Уведомления Оськи адаптированы и проверены в NextKDE с документированными отличиями источника уведомлений и ограничениями.

## Неясности и ограничения

Черновик. Нужен контракт хранения/восстановления и различение удаления в панели и во внешнем источнике. Оговорки файла частично расходятся с уже описанными FT; согласовать действие клика по развёрнутой карточке и семантику прочитанности.

Уточнение пользователя 2026-10-23: показывать все системные уведомления, независимо от приложения-источника и категории события, сохраняя запрос и фокус. В требованиях снят whitelist источников/типов и допущены все уровни критичности; настройки уведомлений и «Не беспокоить» сохраняются. По макету `launchpad-search-notification.png` локальная выдача остаётся выше; карточка располагается непосредственно над строкой поиска, центрируется по ней и занимает ширину центрального острова Оськи. Слева используется иконка приложения уведомления, справа — иконка события. Очередь/стопка остаются в объёме PANEL-005.

Уточнение пользователя 2026-10-23: в компактной карточке показывать только заголовок уведомления, без описания; карточке и истории, открываемой по колокольчику, оставить 8 px отступа от острова. Историю открывать над центром острова Оськи шириной острова.

Повторное уточнение пользователя 2026-10-23: меню колокольчика должно занимать всю ширину острова, включая поверхность popup и внутреннюю область истории.
