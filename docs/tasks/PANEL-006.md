## Цель и границы

Реализовать ситуативные индикаторы в собственной оболочке на Qt/QML с общим UI Kit. Системную интеграцию
адаптировать по решениям PANEL-000; не переносить GNOME API и механизм расширений автоматически.
Применимы [ADR-0008](../adr/0008-unified-bottom-panel.md),
[правила панели](../rules/unified-panel.md) и [контракт UI Kit](../../ui-kit/docs/API.md).

## Критерии готовности

- [ ] Условия батареи/зарядки, отсутствия Wi-Fi с учётом Ethernet и разрыва ранее подключённого VPN реализованы без дубликатов.
- [ ] Пара микрофон/звук появляется при активном capture stream, управляет общими ресурсами и исчезает после последнего пользователя.
- [ ] Команды отражают подтверждённое состояние; ошибки одного источника не ломают остальные, после сна/переподключения выполняется синхронизация.
- [ ] Состав общий между мониторами; при скрытии элемента фокус переходит на доступный соседний элемент.

### Готовность по проектам

- Sirca [ ] Ситуативные индикаторы и состояния системных источников реализованы и проверены в Sirca по основной карточке.
- NextKDE [ ] Ситуативные индикаторы адаптированы и проверены в NextKDE; поддерживаемые источники и ограничения зафиксированы.
