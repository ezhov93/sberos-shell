## Цель и границы

Адаптировать календарь в собственной оболочке на Qt/QML с общим UI Kit. Системную интеграцию
адаптировать по решениям PANEL-000; не переносить GNOME API и механизм расширений автоматически.
Применимы [ADR-0008](../adr/0008-unified-bottom-panel.md),
[правила панели](../rules/unified-panel.md) и [контракт UI Kit](../../ui-kit/docs/API.md).

## Критерии готовности

- [ ] Панель и календарь используют согласованные системные параметры, локаль и часовой пояс; изменения применяются без перезапуска.
- [ ] Открытие всегда показывает текущий месяц; навигация через границу года не меняет системную дату и заголовок текущего дня.
- [ ] Сетка учитывает первый день недели, текущую дату и номера недель; проверены сон, смена дня и форматы 12/24 часа.
- [ ] В сессии один popup на мониторе вызова; Esc возвращает фокус на часы, переключение с Quick Settings выполняется одним действием.

## Неясности и ограничения

Требует согласования статус утверждения и источник системных настроек часов на KWin. В исходнике повреждён UI-индекс; не назначать ему новый номер молча. События/встречи на картинке не расширяют автоматически FT.
