# PANEL-008: Адаптировать календарь

- **Статус:** В работе
- **Обновлено:** 2026-10-23
- **Источник:** [требования](../sources/panel/calendar.md)
- **Требования:** `FT_SMART_PANEL_CALENDAR_1–11; UI_SMART_PANEL_CALENDAR_*`
- **Сценарии реестра:** 05-11; 09-02; 09-24; область 04 (области требуют детализации перед реализацией).
- **Зависимости:** PANEL-000, PANEL-001
- **Основание:** разбор источников от 2026-10-22; задача фиксирует работу, а не утверждает черновые требования.

## Цель и границы

Адаптировать календарь в собственной оболочке на Qt/QML с общим UI Kit. Системную интеграцию
адаптировать по решениям PANEL-000; не переносить GNOME API и механизм расширений автоматически.
Применимы [ADR-0008](../adr/0008-unified-bottom-panel.md),
[правила панели](../rules/unified-panel.md) и [контракт UI Kit](../../ui-kit/docs/API.md).
Уточнение пользователя от 2026-10-22: в Sirca использовать календарь из UI Kit, убрать часы из окна
календаря, а подпись кнопки календаря оформить по FT_CALENDAR_1.

## Критерии готовности

- [ ] Панель и календарь используют согласованные системные параметры, локаль и часовой пояс; изменения применяются без перезапуска.
- [ ] Открытие всегда показывает текущий месяц; навигация через границу года не меняет системную дату и заголовок текущего дня.
- [ ] Сетка учитывает первый день недели, текущую дату и номера недель; проверены сон, смена дня и форматы 12/24 часа.
- [ ] В сессии один popup на мониторе вызова; Esc возвращает фокус на часы, переключение с Quick Settings выполняется одним действием.

## Неясности и ограничения

Требует согласования статус утверждения и источник системных настроек часов на KWin. В исходнике повреждён UI-индекс; не назначать ему новый номер молча. События/встречи на картинке не расширяют автоматически FT.

## Следующий шаг

Определить источник системных предпочтений часов/номеров недель для KWin и применить их без
собственных настроек; затем проверить оставшиеся критерии Sirca в Wayland. Отдельно выполнить
критерии NextKDE в его рабочей копии.

## Проверки и результат

Этап Sirca: самодельные сетка и навигация заменены `Sber.CalendarView`; крупные часы и секунды
удалены из календарного окна; заголовок текущей даты и список событий сохранены. Подпись кнопки
показывает локализованные сокращённый день, число, сокращённый месяц и 24-часовое время без секунд
(FT_SMART_PANEL_CALENDAR_1, сценарии 05-11 и 09-02). UI Kit не даёт слота для точек событий в ячейках;
события выбранного дня и ближайшее событие остаются доступны в окне.

2026-10-23: компактная кнопка календаря в Sirca приведена к виду макета
`calendar-light.png`/`calendar-dark.png`: иконка часов, короткая дата и время через точку;
размер подписи ограничен 13 px, дата локализуется, формат времени — 24-часовой с ведущим нулём.
Затронуты сценарии 05-11 и 09-02/09-24. NextKDE в область этой правки не входит.

Уточнение пользователя 2026-10-23: иконку часов убрать, быстрые настройки и календарь
расположить с промежутком 2 px; компактировать кнопку по ширине текста и прижать
группу к правому краю системной зоны.

2026-10-23: строке правой зоны явно задана ширина по её содержимому, чтобы
привязка группы к правому краю рассчитывалась по фактической ширине. Сборка прошла;
оболочка запущена в графической сессии и загрузила QML. Визуальную сверку не выполнял.
