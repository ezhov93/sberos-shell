## Цель и границы

Реализовать полноэкранный Launchpad в собственной оболочке на Qt/QML с общим UI Kit. Системную интеграцию
адаптировать по решениям PANEL-000; не переносить GNOME API и механизм расширений автоматически.
Применимы [ADR-0008](../adr/0008-unified-bottom-panel.md),
[правила панели](../rules/unified-panel.md) и [контракт UI Kit](../../ui-kit/docs/API.md).

## Критерии готовности

- [ ] Открывается один полноэкранный Launchpad на мониторе вызова; обычная панель скрывается, поле поиска сразу готово к вводу.
- [ ] Сетка содержит максимум 8 колонок × 4 ряда, адаптирует вместимость и поддерживает страницы с индикатором.
- [ ] Поиск только по названиям приложений начинается с первого символа; документы и корпоративный поиск не отображаются.
- [ ] Esc/свободный фон закрывают без запуска; выбор приложения сразу закрывает экран, уведомления сохраняют ввод и фокус.

## Неясности и ограничения

Черновик. GNOME-навигацию необходимо описать для QML. Текущий встроенный лаунчер не подтверждает выполнение полноэкранных сценариев.
