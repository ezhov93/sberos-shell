## Цель и границы

Локальный браузерный мок для просмотра и обсуждения состояний Smart Panel:
реальные HTML-контролы, оформление по исходным изображениям, исходные SVG/PNG для
сравнения. Для общей композиции и геометрии ориентироваться в первую очередь на
SVG-макеты из `docs/sources/panel/svg/`; скриншоты использовать для деталей и
состояний, которых в макетах нет. Промежуточная замена интерфейса на галерею
была решением агента,
а не уточнением пользователя; прежняя запись карточки о таком уточнении исправлена.

Страница не заменяет ТЗ, ADR и карточки реализации Sirca/NextKDE. Системные
действия демонстрационные. Исходники оболочек и `refs/` вне области этой задачи.

## Проверки и результат

`node --check docs/mock/smart-panel/mock.js` прошёл. Временная проверка в Node VM
с подставным DOM прошла для всех 26 состояний, существования связанных SVG/PNG,
поиска «сбер» (7 результатов), пустой выдачи, уведомления, календарных границ
года/високосного февраля, Wi-Fi, Bluetooth, питания и +N. Добавлены проверки шести локальных
документов,
пустой локальной выдачи и очистки списка из трёх уведомлений. Это не проверка CSS.

Основные кадры панели, меню, Launchpad, календаря, Quick Settings и дочерних
форм просмотрены как локальные изображения. Размеры и известные отклонения
записаны в README мока. Браузер отказал в чтении уже открытой пользователем
`file:` вкладки из-за политики разрешённых протоколов. Ограничение не обходилось;
снимки HTML и браузерный обход остаются открытыми. Qt не используется.

### Этап SVG, 2026-10-25

SVG стали основным источником геометрии. Извлечены чистые обои, слой рабочего
стола, аватар, 32 значка приложений и 24 значка интерфейса/файлов. Быстрые
настройки приведены к 488×540 с подписями «Звук» и «Дисплей»; дочерние формы
Wi-Fi/Bluetooth — к 344×596/344×556. Добавлены локальный поиск 456×653 и список
уведомлений 456×354. Источники и SHA-256 записаны в manifest, оригиналы не менялись.
Извлечённые значки просмотрены после офлайн-рендера. SVG и PNG используются
в наложении; браузерная проверка по-прежнему недоступна. Различия MVP и источника
(корпоративный поиск, счётчик уведомлений, страницы Launchpad) записаны в README.

## Неясности и ограничения

Текст SVG переведён в контуры: точное название шрифта неизвестно. Blur 22 px,
размеры, цвета и основные системные значки извлечены из SVG; градиенты CSS
приблизительные. Исходные PNG отличаются размерами и состояниями служб.
Есть известные различия: четыре пункта меню MVP вместо пяти исходных; одна
страница из доступных 32 приложений; звуковые индикаторы пока только в галерее.
Режим прозрачности мока служит сравнению с исходным материалом и не меняет
принятых правил рабочих оболочек; рядом доступен непрозрачный вариант.

## Следующий шаг

Перезагрузить открытую страницу и выполнить браузерную сверку: «Мок · управление» →
выбрать состояние → «Сверить с оригиналом». Проверить обе темы, Esc, Tab/Shift+Tab,
поиск и календарь, сохранить снимки. После визуальной сверки исправить оставшиеся
расхождения и закрыть критерий, затем архивировать карточку.
