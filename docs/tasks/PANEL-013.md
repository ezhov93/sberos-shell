# PANEL-013: Выделить остров значков приложений трея Sirca

- **Статус:** В работе
- **Обновлено:** 2026-10-26
- **Источник:** уточнение пользователя от 2026-10-26; [правила единой панели](../rules/unified-panel.md)
- **Требования:** уточнение границы визуальной зоны приложений трея
- **Сценарии реестра:** `03-14`, `07-09`, `07-13`, `09-24`
- **Зависимости:** PANEL-001, PANEL-006, ADR-0008
- **Основание:** пользователь попросил, чтобы остров трея Sirca показывал только приложения трея.

## Цель и границы

Оставить в статусной зоне панели Sirca только остров приложений `StatusNotifierItem`.
Предыдущая строка системных индикаторов и действий удалена по прямому запросу
пользователя. Quickshell и AeroThemePlasma не входят в эту карточку.

## Критерии готовности

- [x] Остров трея содержит только активные видимые значки приложений, сохраняя меню и действия значков.
- [x] Предыдущая строка системных индикаторов и действий удалена; в статусной зоне остался только tray.
- [x] При отсутствии значков приложения пустой остров трея скрыт.
- [ ] Проверены ширина панели 1920 px в обеих темах, переполнение значков, открытие меню и маска ввода в Wayland.
- [x] Результат согласован с правилами панели; охват сценариев указан.

## Проверки и результат

Команда `cmake --build build -j 4` из `shell/shell/` прошла (код 0), затем
`timeout 25s ./build/bin/sirca-shell --check` под Wayland сообщил `81` QML-файл
и `0` ошибок. Установленная служба использует тот же бинарник (SHA-256
`ebf041d72714eee373c2afe07777e56b0ed877be5e63964afc68b8d3a474dbee`), активна,
`NRestarts=0`. Снимок панели подтверждает удаление прежней строки в светлом режиме.
Снимок: [светлая тема](evidence/PANEL-013/tray-light.png); окружение — Qt 6.11.2,
Plasma/KWin Wayland.
В конфиге нет списка скрытых значков; StatusNotifierWatcher зарегистрировал два
элемента, но на снимке их значки не видны. Попытка применить тёмный режим правкой
файла не изменила живую тему; исходный конфиг восстановлен побайтно.

В `UnifiedPanel.qml` в статусной зоне оставлен только `Tray`; часы и Quick Settings
остаются отдельно. Остров рассчитывается по ширине видимых значков, ограничен
10% ширины экрана, прокручивается и сохраняет меню/жесты. При пустом tray его
ширина равна нулю. Поведение отображения значков, обе темы, переполнение, popup
меню и маска ввода в Wayland ещё не подтверждены. Сценарии `03-14`, `07-09`,
`07-13` и `09-24` не закрыты.

## Следующий шаг

Проверить видимость активных значков на живой панели, затем ширину 1920 px в
обеих темах, пустой tray, переполнение, popup меню и маску ввода в Wayland.
