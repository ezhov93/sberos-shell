- **FT/UI:** `UI_SBEROS_PANEL_USSURI_1.1`; семейства `FT/UI_SMART_PANEL_SBER_BUTTON`, `APPLICATIONS`, `OSKA`, `NOTIFICATIONS`, `QUICK_SETTINGS`, `CALENDAR`, `LAUNCHPAD` из [Smart Panel](../sources/panel/SMART_PANEL.md).

- **Зависимости:** PANEL-003–012, SHELL-001, UIKIT-001, QS-001, QS-004; ADR-0006–0011.

## Цель и границы

Вся представленная в моке часть MVP должна соответствовать его композиции,
размерам, графике, прозрачности/blur и показанным визуальным состояниям.
Цель общая для Sirca и Quickshell. Реальные системные сценарии и состав MVP
определяются ТЗ и явными решениями пользователя. `refs/` сохраняется.

Эта карточка объединяет критерии и расхождения; изменения QML, UI Kit и сервисов
ведутся в существующих карточках блоков. Подробная матрица —
[mock-parity.md](../rules/mock-parity.md). Перенос завершённой оболочки целиком
в другой проект и автоматический выбор основы здесь не предполагаются.

Подходящие общие компоненты UI Kit использовать; палитру и стиль переиспользуемых
controls выравнивать по моку в UIKIT-002. Новые композиции и специфичные для панели
поверхности реализовывать отдельными компонентами в QML-коде каждой оболочки.
Приёмку выполнять раздельно: проекты используют собственные архитектуры и сервисные
границы.

## Результат текущего этапа

Зафиксирован новый визуальный критерий MVP и выбор материала. Обновлены правила
и SHELL-001; прежние описания непрозрачного оформления остаются историей этапов.
Прямые запреты в старых критериях QS-001/PANEL-010/012 заменены ADR-0011 для
представленных в моке поверхностей; при продолжении этих задач применять новый
критерий. Меню питания HTML приведено к пяти ранее согласованным действиям MVP;
команды с обновлением удалены. Изменения QML, сборка, тесты и визуальная
приёмка этим этапом не выполнялись.

## Проверки этапа

Ссылки новых документов сверены с файлами; подготовленный diff просмотрен,
`git diff --cached --check` прошёл. `node --check docs/mock/smart-panel/mock.js`

приёмка обеих оболочек остаётся открытой.

## Неясности и ограничения

Способ фонового blur нужно проверить отдельно в каждой реализации. Имя исходного
шрифта неизвестно; погрешность в пикселях не согласована. Два демонстрационных действия питания с обновлением из версии `6e48fb5`
удалены по прежнему решению пользователя в PANEL-012. Браузерная проверка HTML остаётся открытой в PANEL-011.
