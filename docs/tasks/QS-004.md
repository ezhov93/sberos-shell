# QS-004: Реализовать полноэкранное меню приложений Quickshell

- **Статус:** В работе
- **Обновлено:** 2026-10-23
- **Источник:** [требования и макеты панели приложений/Launchpad](../sources/panel/applications.md); запрос пользователя от 2026-10-23.
- **Требования:** `FT_SMART_PANEL_LAUNCHPAD_1–6`; UI `UI_SMART_PANEL_LAUNCHPAD_1–6`.
- **Сценарии:** `02-02`, `02-04`, `09-24`; область `04` для вывода на экран вызова.
- **Зависимости:** PANEL-010, QS-001.

## Цель и границы

Привести меню приложений Quickshell к полноэкранному Launchpad по требованиям и
скриншотам источника. Использовать существующие каталог приложений, запуск,
поиск, пагинацию и привязку к экрану. Поиск ограничить отображаемыми названиями.
Доработка относится к `quickshell/`; Sirca остаётся в PANEL-009.

## Критерии готовности

- [x] Открытие по умолчанию показывает полноэкранный Launchpad; нижняя/центральная
  карточные формы и настройка формы удалены из пользовательского интерфейса.
- [x] Текущие обои KDE размыты на фоне Launchpad; поверх изображения остаётся
  полупрозрачная токенизированная подложка для контраста.
- [x] Экран скрывает панель, поиск находится по центру снизу, приложение запускается
  выбором из сетки, Esc закрывает экран, а первый Esc при запросе очищает его.
- [x] Поиск реагирует на каждый символ и совпадает только по отображаемому имени;
  пустой результат сохраняет запрос и показывает пустое состояние.
- [x] Нижнее поле Launchpad приведено к макету: центрировано, высотой 73 px,
  шириной до 456 px, с нижним отступом 8 px; пустое состояние говорит «Nothing found».
- [x] В сетке не более 8 столбцов и 4 строк; размер иконки/интервал по макету;
  страницы переключаются точками и штатной клавиатурной/указательной навигацией.
- [ ] Проверены визуально светлая и тёмная темы, keyboard focus, размеры 1280/1440/1920
  и выбор экрана на Wayland; сохранены снимки.

### Готовность по проектам

  в PANEL-009.
- NextKDE [ ] Quickshell Launchpad реализован и проверен по критериям выше.

## Ограничения и следующий шаг

Источник остаётся черновым, абсолютные размеры и цвета сверяются по приложенным
скриншотам. Далее запустить отдельный предпросмотр Quickshell, сверить обе темы,
клавиатурный фокус и сетку на референсных разрешениях, сохранить снимки и обновить
результат проверки.

## Проверки и результат

Первый этап: существующий Quickshell AppLauncher переведён на полноэкранную форму по
умолчанию, альтернативные формы убраны из настроек, а прежняя сохранённая форма
больше не принимается. Полноэкранная сетка ограничена 8 столбцами и 4 строками,
размер большой иконки установлен в 120 px, интервал — 16 px. Поиск больше не
сопоставляет desktop ID, только имя приложения. Панель скрывается при открытом
Launchpad. Предпросмотр `./tools/kosctl run` поднялся на Wayland (сессия `28807`, DP-7
2560×1440). После добавления фона Quickshell автоматически перезагрузил конфигурацию
(`Configuration Loaded`); IPC подтвердил `AppLauncherService open=true`. CUA не
предоставил окно/снимок для визуальной оценки. Platform/data-сервисы предпросмотра
недоступны, поэтому проверки реального desktop-состояния не выполнены.

2026-10-23: строка поиска Launchpad приведена к геометрии макета для DP-7 1920×1080:
ширина до 456 px, высота 73 px, нижний отступ 8 px, текст 16 px. Пустая выдача
показывает локализуемое сообщение `Nothing found`; сохранение запроса и очистка
по-прежнему управляются существующим полем. `cmake --build .build/kosctl -j2`
завершился сообщением `ninja: no work to do`, то есть QML не был перекомпилирован.
`qmllint` завершился с кодом 0, но без настроенных путей импорта сообщил о неизвестных
модулях Quickshell; полноценная QML-проверка не подтверждена. Визуальная сверка ещё
не выполнена. Макет также показывает аватар Оськи и баннер уведомления над полем;
в текущей копии Quickshell подходящего ресурса аватара нет, а показ системных
уведомлений над Launchpad остаётся отдельной незавершённой интеграцией PANEL-005.

2026-10-23: контекстное меню Launchpad больше не показывает нижние/центральные
режимы, которые конфигурация уже отклоняла. Удалены неиспользуемая команда
`updateDisplayMode` из IPC и её C++ bridge; переход к настройкам Launchpad сохранён.
Удалены и переводы этих пунктов из общего каталога локализации.
`cmake --build .build/kosctl --parallel 2` прошёл. Первичный запуск CTest в sandbox
прошёл 21/24; оставшиеся три проверки не смогли создать D-Bus-сокеты. После
повторного запуска этих трёх проверок вне sandbox все прошли; итог 24/24.
Визуальность на экране не подтверждена; снимок DP-5 из живой сессии остаётся чёрным.

## Коммиты

Изменения остаются в незакоммиченном рабочем дереве. `quickshell/` — добавленный
исходный снимок, а рабочее дерево содержит посторонние незакоммиченные изменения;
перед отдельной фиксацией требуется проверить границы индексируемых файлов.
