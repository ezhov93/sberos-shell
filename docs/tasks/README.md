# Реестр задач

Это постоянная память о запланированной работе между чатами. Спецификация описывает
требуемое поведение, ADR — принятое решение, задача — объём работы и её состояние.
Постановка задачи не утверждает черновик источника и не означает завершённую реализацию.

## Порядок работы

1. Перед работой прочитать реестр и карточку по области запроса; обновить существующую,
   если запрос её продолжает. Для новой работы создать карточку со стабильным ID.
2. Указать цель, источник и FT/UI, ID сценариев, зависимости, критерии готовности,
   неясности, следующий шаг, проверки и коммиты. Не дублировать всю спецификацию.
3. Начав работу, поставить «В работе». При препятствии поставить «Заблокировано»
   и записать конкретную причину и условие продолжения. Зависимости сами по себе
   не переводят запланированную задачу в заблокированные.
4. После проверенной доработки обновить карточку и строку реестра в том же коммите.
   Незавершённые критерии и пропущенные проверки сохранять явно; поставить «Готово»
   только после выполнения всех согласованных критериев. Этап можно закоммитить,
   оставив задачу в работе. Для текущего коммита допустима ссылка через путь в Git,
   для последующих — записывать уже известные хеши; не менять коммит ради собственного хеша.
5. При изменении требований обновлять rules; при архитектурном решении — ADR.
   Источники сохранять, отклонения объяснять. Уточнения пользователя переносить
   из чата в карточку. Готовые задачи не удалять, ID не переиспользовать.

Статусы: **Запланировано**, **В работе**, **Заблокировано**, **Готово**.
В реестре и карточке статус должен совпадать. У каждой незавершённой карточки есть следующий шаг.

## Панель

Источник — [слепок Smart Panel от 2026-10-22](../sources/panel/SMART_PANEL.md)
и его скриншоты. Анализ выявил отличия от текущего объединения панелей:
пять зон и отдельные визуальные блоки, центральная Оська, меню Сбер,
переполнение +N и полноэкранный Launchpad. Объединение из ADR-0008 остаётся
технической основой; PANEL-000 и компоновка PANEL-001 завершены (проверки только 1920 px по ADR-0008);
реализация остальных блоков ещё не выполнена.

Меню Сбер в источнике зафиксировано; приложения, Оська и индикаторы — черновики.
«Новое/адаптировано» у календаря и быстрых настроек обозначает происхождение,
а не утверждение. Источник описывает GNOME/X11/Wayland, проект — Qt/KWin/Wayland;
рамки согласованы в PANEL-000: свой стек, функциональность и внешний вид по требованиям,
без GNOME-адаптации. Корпоративные настройки вне MVP, меню открывает настройки shell.
AI вне MVP.
