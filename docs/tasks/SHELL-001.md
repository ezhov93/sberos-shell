# SHELL-001: Перевести оболочку на цвета UI Kit и непрозрачные поверхности

- **Статус:** Запланировано
- **Обновлено:** 2026-10-22
- **Источник:** прямое указание пользователя от 2026-10-22: перекрасить shell под цвета библиотеки и отказаться от прозрачности.
- **Контракт:** [UI Kit API](../../ui-kit/docs/API.md), [токены](../../ui-kit/docs/API-tokens.md).
- **Сценарии:** `09-01`, `09-02`, `09-19`, `09-21`, `09-24`; связанные области `03`, `05`, `07` уточнить при инвентаризации.
- **Зависимости:** нет; согласование GNOME-адаптации PANEL-000 не требуется для этой задачи.

## Цель и границы

Согласовать оформление всей собственной оболочки с палитрой общего UI Kit:
панели, меню, popup, лаунчер, поиск, уведомления, календарь, быстрые настройки,
переключатель окон, OSD, настройки и режим редактирования. Учитывать unified
и сохраняемый split. Цвета фонов, текста, иконок, границ, выделения и состояний
получать из семантических токенов библиотеки в светлой и тёмной темах.

Отказаться от просвечивания рабочего стола сквозь поверхности интерфейса и
от фонового blur/glass, необходимых для такого оформления. Общие компоненты
UI Kit переиспользовать по контракту; полная замена всех компонентов оболочки
не является условием этой задачи. Системные приложения, содержимое сторонних
апплетов и глобальные эффекты KWin не перекрашивать в рамках этой работы.

Это явное уточнение проекта к скриншотам Smart Panel: сохраняются компоновка
и сценарии, но прозрачные/размытые поверхности макетов не воспроизводятся.
Исходные скриншоты не изменять.

## Критерии готовности

- [ ] Составлена инвентаризация собственных поверхностей и цветов; каждой роли сопоставлен документированный токен UI Kit, исключения объяснены.
- [ ] Все перечисленные поверхности используют палитру UI Kit и обновляются при переключении темы без перезапуска; нет независимой палитры Sirca и пользовательского оттенка, обходящего выбранные токены.
- [ ] Фоны видимых поверхностей полностью непрозрачны в установившемся состоянии. Обои не меняют читаемость текста, иконок и состояний hover/pressed/disabled/focus/selected.
- [ ] Удалены вызовы и зависимости оболочки от фонового blur/glass для этих поверхностей, а также предупреждения о необходимости Glass. Глобальные настройки эффектов композитора не изменяются.
- [ ] Неактуальные настройки прозрачности, blur/glass и произвольной перекраски убраны из интерфейса; старые сохранённые значения безопасно игнорируются и не возвращают прежнее оформление. Политика совместимости конфигурации записана.
- [ ] Прозрачные области вне формы окна, скругления, маски и пропуск ввода сохранены: отказ от прозрачных фонов не создаёт прямоугольные заливки вокруг панелей и popup. Тени и анимации появления/скрытия допустимы, но не возвращают постоянное просвечивание содержимого.
- [ ] Сохранены открытие/закрытие, фокус, работа окон, системных элементов и расположение панелей; размеры и компоновка меняются только при необходимости миграции оформления.
- [ ] Обновлены применимые README, rules и ADR с описанием решения, границ и оставшихся исключений; PANEL-001 и другие связанные карточки согласованы с новым оформлением.

- Проверить актуальность API-контракта, собрать оболочку, выполнить применимые изолированные проверки затронутых компонентов.

- Проверить документационные ссылки и `git diff --check`; не добавлять тесты, повторяющие реализацию только ради покрытия.

## Неясности и ограничения

Точные токены и охват устаревших эффектов определить по инвентаризации перед
правками. Если библиотека не предоставляет нужную непрозрачную роль, выбрать
документированный непрозрачный токен либо дополнить UI Kit и контракт в рамках
явно описанного изменения; не придумывать скрытый API и параллельную палитру.
Удаление общего кода эффектов допустимо после проверки остальных потребителей;
отказ от прозрачности не означает удаление поддержки апплетов.
