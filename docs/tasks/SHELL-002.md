# SHELL-002: Удалить старую двухпанельную раскладку Sirca

- **Статус:** В работе
- **Обновлено:** 2026-10-22
- **Источник:** прямое указание пользователя от 2026-10-22: «сплит убираем».
- **Требования:** единая нижняя панель по [ADR-0008](../adr/0008-unified-bottom-panel.md)
  и [правилам](../rules/unified-panel.md).
- **Сценарии:** 03-01, область 04, 09-02.
- **Зависимости:** PANEL-001, ADR-0008.

## Цель и границы

Оставить в Sirca только единую нижнюю панель. Удалить отдельный TopBar,
переключение раскладки, отдельные настройки и редактор верхней панели,
двухпанельную маршрутизацию popup и проверки split. Старый ключ panelLayout
игнорировать. Старые screens.bar/screens.dock продолжить учитывать для
определения видимости панели, не переписывая конфигурацию автоматически.

Настройки прозрачности и KWin Glass-эффект относятся к SHELL-001, кроме
параметров и кода, использовавшихся только удалённым TopBar.

## Критерии готовности

- [x] В QML/C++ создаётся только UnifiedPanel; отдельный TopBar и режим split удалены.
- [x] Настройки и редактор показывают только параметры единой панели.
- [x] Старый ключ panelLayout со значением split не создаёт дополнительные поверхности.
- [x] Старые экранные ключи bar/dock остаются fallback для настройки видимости панели.
