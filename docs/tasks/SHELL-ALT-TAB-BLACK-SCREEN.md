# SHELL-ALT-TAB-BLACK-SCREEN: Не скрывать рабочий стол при Alt+Tab без plasmashell

- **Статус:** В работе
- **Обновлено:** 2026-10-26
- **Источник:** сообщение пользователя от 2026-10-26
- **Сценарии:** `03-01`, `03-04`
- **Зависимости:** —

## Цель и границы

Исправить переключение окон Sirca в режиме без `plasmashell`: после Alt+Tab
рабочий стол, обои и панель не должны заменяться чёрным экраном с одним окном
переключателя. Область — переключатель окон Sirca в `shell/`.

## Критерии готовности

- [x] Переключатель не вызывает KWin HighlightWindow при открытии и перемещении выбора.
- [ ] Alt+Tab и Alt+Shift+Tab проверены в Wayland-сеансе без `plasmashell`:
  фон, панель и выбранное окно остаются видимыми.
- [ ] Проверено переключение с работающим `plasmashell`.

## Неясности и ограничения

Пользователь сообщил, что в режиме без `plasmashell` остаётся только окно
переключателя, а фон, обои и панель исчезают. Изоляция текущей среды не даёт
доступа к пользовательской D-Bus-сессии, поэтому живое воспроизведение пока
невозможно. Предварительный KWin HighlightWindow удалён как наиболее вероятный
источник изменения видимости/стека окон; гипотеза требует проверки в Wayland.

## Следующий шаг

Проверить переключение в пользовательском Wayland-сеансе с отключённым и
включённым `plasmashell`.

## Проверки и результат

Проверка кода показала, что QML-переключатель вызывал KWin HighlightWindow при
показе и каждом изменении выбранного окна. Вызовы удалены; окно активируется
только при подтверждении выбора. `cmake --build build --target sirca-shell -j4`
прошла. Проверка на живом Wayland-сеансе ещё не выполнена.
