## Цель и границы

Создать воспроизводимое покрытие значимого поведения C++ и QML в `shell/shell/`
и `ui-kit/`: моделей, конфигурации, публичных контрактов компонентов и взаимодействий
интерфейса. Использовать Qt Test для C++ и Qt Quick Test для QML, развивать
существующие проверки, не дублировать их. Референсный NextKde и сторонние проекты
не входят в объём задачи.

Начальная база: `ui-kit/tests/test_plugin_load.cpp`, `ui-kit/tests/tst_slider.qml`,
изолированные тесты настроек и smoke-проверки панели в `shell/shell/tests/`.
Проверка API-каталога, сборка, smoke и снимки не заменяют тесты поведения.

## Организация параллельной работы

Тесты стабильных компонентов можно разрабатывать параллельно с PANEL-002 и
SHELL-001. Правки общих CMake-файлов, runner и тестируемых компонентов согласовывать
и вносить последовательно. Новое поведение брать из согласованного контракта,
не закреплять тестами промежуточную реализацию другой задачи.

## Неясности и ограничения

Точный перечень компонентов, этапы и численные цели покрытия пока не согласованы.
Сначала нужна инвентаризация; задача не обещает покрытие всего кода или всех
сценариев DE. Доступность Qt Test/Qt Quick Test и средств измерения покрытия
проверить при начале реализации. Метрики покрытия допустимы как диагностика.

## Первый ограниченный этап: регрессии SHELL-008

| Компонент / риск | Сценарий и тест | Ограничение |
|---|---|---|
| `CalendarModel`: дрейф месячной/годовой даты | `tests/cpp/test_calendarmodel.cpp`, CTest `test_calendar_model`; проверены DTSTART 31 января и 29 февраля | Не покрыты часовые пояса, исключения и остальные RRULE |
| `Lyrics`: lookup застревает после выключения | `tests/cpp/test_lyrics.cpp`, CTest `test_lyrics`; сетевой менеджер подменён локальным stub | Не проверен реальный TLS/API LRCLIB |
| `ClipboardModel`: отложенная запись теряется при завершении | `tests/cpp/test_clipboardmodel.cpp`, CTest `test_clipboard_model`; XDG data временный | Реальный Wayland clipboard не участвует |
| `Shell`: повреждённый config затирается | `tests/cpp/preserve_invalid_config.qml` + `test_invalid_config_preserved.py`; отдельная D-Bus-сессия и временные XDG-каталоги | Offscreen не проверяет watcher в рабочей сессии |
| `RemovableModel`: занятое устройство | `tests/cpp/test_removable_busy_eject.cpp`, CTest `test_removable_busy_eject`; два файловых объекта на одном диске в приватной D-Bus-сессии | Проверяется отказ eject; реальное устройство не затрагивается |
| Создание ярлыка: отказ установки прав | `tests/cpp/test_desktopshortcut_permissions.cpp`, CTest `test_desktopshortcut_permissions`; setter прав внедрён и возвращает ошибку | Проверяется удаление частичного файла; файловая система рабочего стола не меняется |
| `TrayItem`: устаревшие ответы | `tests/cpp/test_tray_request_serials.cpp`, CTest `test_tray_request_serials`; проверены serial refresh и property fetch | D-Bus-порядок дополнительно покрыт живыми Wayland menu/layout smoke |

Инфраструктура активируется только параметром `-DSIRCA_BUILD_TESTS=ON`; обычная
сборка shell не требует Qt Test. Qt Test и Python 3 проверяются при включении
этого режима.
