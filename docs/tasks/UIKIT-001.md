## Цель и границы

Улучшить надёжность, сопровождаемость и подключение общей библиотеки оболочки
и приложений. Первичный [разбор и предложения](../../ui-kit/docs/refactoring-review.md)
содержит подтверждённые статические находки, ограничения и порядок работ.
Запрос пока разрешает анализ; предложенные изменения API и архитектуры не считаются
принятыми решениями. Реализация не начата.

## Предлагаемые этапы

1. Регрессионные тесты и поведение TextField/ComboBox, загрузка темы, ошибки File/Process.
2. CMake, упаковка, версии и ресурсы без зависимости установленного пакета от исходников.
3. Общие состояния компонентов, типизация внутренних свойств и границы публичного API.
4. Совместимые новые имена API и матрица примеров галереи.

## Критерии готовности

- [ ] Зафиксирован согласованный объём первого этапа и политика совместимости; для архитектурных решений обновлён или создан ADR, где применимо.
- [ ] Подтверждённые дефекты выбранного этапа исправлены и защищены тестами; оставшиеся находки имеют явный следующий шаг.
- [ ] Поведение, API, каталоги токенов/объявлений и README согласованы; старые имена не удалены без плана миграции потребителей.
- [ ] Проверены сборка, CTest и API-контракт; для сборки/ресурсов — временная установка и запуск без исходников.
- [ ] Для визуальных изменений сохранены и просмотрены снимки до/после обеих тем; записаны Qt, платформа, сценарии и ограничения Wayland.
- [ ] Проверены затронутые потребители shell; объём следующих этапов отделён от выполненного.

## Неясности и ограничения

Полного аудита 79 QML-компонентов и всего C++ пока нет. Процент покрытия и
целевые платформы сверх текущего окружения не определены. Массовое переименование,
смена визуального дизайна и удаление модулей не утверждены. Нельзя автоматически
считать все предупреждения линтера дефектами поведения.
