# UIKIT-002: Подогнать палитру и общие controls UI Kit под Smart Panel

- **Статус:** В работе
- **Обновлено:** 2026-10-26
- **Источник:** запрос пользователя от 2026-10-26; `docs/mock/smart-panel/styles.css`, `README.md`, HTML-мок и `docs/adr/0011-mock-visual-target.md`.
- **FT/UI:** UI Kit; визуальные токены и общие интерактивные элементы Smart Panel.
- **Сценарии:** `FT_SMART_PANEL_SBER_BUTTON_1–8`, `FT_SMART_PANEL_APPLICATIONS_1–15`, `FT_SMART_PANEL_OSKA_1–5/7`, `FT_SMART_PANEL_NOTIFICATIONS_1–17`, `FT_SMART_PANEL_QUICK_SETTINGS_1–24`, `FT_SMART_PANEL_CALENDAR_1–11`, `FT_SMART_PANEL_LAUNCHPAD_1–6`; для настроек UI Kit — `09-02`, `09-19`, `09-21`, `09-24`.
- **Зависимости:** UIKIT-001 — API-контракт и инвентарь; ADR-0011.

## Цель и границы

Согласовать светлую и тёмную палитры UI Kit с материалами, контрастом и
акцентами HTML-мока, а также обновить общие размеры и controls, которые
переиспользуются оболочкой и приложениями. Мок определяет внешний вид; системные
состояния, данные и поведение остаются по FT/UI. Новые панели и композиция
Smart Panel принадлежат QML соответствующей оболочки.

## Критерии готовности

- [ ] Общие палитры светлой и тёмной тем согласованы с цветами мока и каталогом токенов.
- [ ] Переиспользуемые controls используют согласованные радиусы, поверхности и акценты.
- [ ] API-контракт, README и карточки оболочек отражают границы и совместимость.
- [ ] Изменения проверены сборкой UI Kit и галереей в обеих темах; снимки просмотрены.
- [ ] Влияние на Sirca и Quickshell зафиксировано отдельно; незакрытые визуальные состояния оставлены открытыми.

## Проверки и результат

Работа начата с цветов темы и общих радиусов. Свойства мока: светлый текст
`#484c5b`, muted `#9296a6`, основной фон `rgba(247,249,251,.72)`, внутренний
`rgba(255,255,255,.92)`, teal accent `#4da7a1`; тёмный текст `#e5e8ed`, muted
`#959ba8`, фон `rgba(45,62,58,.85)`, внутренний `#2b323b`, hover `#363e48`.
В `sdds_os.json` обновлены роли текста, поверхностей, акцента и фоновые роли
для светлой/тёмной темы; `sizes_os.json` получил радиусы 10/16/24 для базовых
контролов, внутренних поверхностей и панелей. `Menu`, `Dialog` и `ArrowRectangle`
используют радиусы, согласованные с моком; контуры меню/всплывающих поверхностей
переведены на токен outline. API-контракт переведён на редакцию 4.

`python3 ui-kit/tools/api_contract.py --write` и `--check` прошли; `cmake --build
ui-kit/_build -j 4` прошёл. Галерея запущена в обеих темах, снимки просмотрены и
сохранены в `ui-kit/examples/gallery/screenshots/2026-10-26/` (Qt 6.11.2, Linux,
offscreen/software). Первичный запуск блокировал унаследованный `QT_STYLE_OVERRIDE=kvantum`;
сброс переменной устранил проблему. CTest и Wayland не запускались. Визуально
проверен экран кнопок; остальные компоненты и потребители shell требуют отдельной
сверки.
