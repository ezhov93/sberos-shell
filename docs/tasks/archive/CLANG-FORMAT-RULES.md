- **Требования FT/UI:** не применимо; задаётся формат исходного кода.

## Цель и границы

Добавить корневой `.clang-format` и применить его к C++ исходникам UI Kit
и Sirca Shell. Не применять правила к `refs/`, сторонним материалам
`ui-kit/upstream/`, сгенерированному коду и каталогам сборки.

## Критерии готовности

- [x] Корневая конфигурация задаёт единый отступ в четыре пробела, ширину строки
  100 символов, стиль скобок и указателей, сохраняет порядок include.
- [x] Конфигурация принимается установленным `clang-format`.
- [x] Все C++ исходники UI Kit и Sirca Shell отформатированы, повторная проверка
  не находит расхождений.
- [x] Изменения не затрагивают поведение, API, зависимости или сборку.

## Готовность по проектам

- Sirca и UI Kit: 92 C++ исходника отформатированы.
- NextKDE: `refs/NextKde/` исключён; файлы не менялись.

## Результат

Конфигурация основана на LLVM с четырьмя пробелами, колонкой 100, скобками в стиле
Attach, выравниванием указателей вправо, без сортировки include и без табуляции.
`clang-format --style=file --dump-config` и повторная проверка 92 файлов через
`clang-format --dry-run --Werror` завершились успешно; `git diff --check -- ui-kit shell`
прошёл. Сборки и тесты не выполнялись: менялось только форматирование.
