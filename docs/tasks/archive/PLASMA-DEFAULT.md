# PLASMA-DEFAULT: Сделать Plasma Smart Panel основной для пользователя

- **Статус:** Готово
- **Обновлено:** 2026-10-27
- **Источник:** прямой запрос пользователя «сделай что бы у меня моя plasma-theme была по умолчанию»; [ATP-001](../ATP-001.md), [Smart Panel](../../../plasma-theme/SMART-PANEL.md).
- **FT/UI:** `UI_SBEROS_PANEL_USSURI_1.1`; пользовательская настройка запуска, новых требований к интерфейсу нет.
- **Сценарии:** `03-01` (основная панель), `02-02` (запуск приложений); полная приёмка остаётся в ATP-001.

## Возврат к обычной Plasma

Удалить только созданный drop-in и перезапустить штатную службу:

```sh
rm ~/.config/systemd/user/plasma-plasmashell.service.d/sberos-shell.conf
systemctl --user daemon-reload
systemctl --user restart plasma-plasmashell.service
```

При необходимости прежний профиль SberOS восстанавливается из резервной копии
при остановленной `plasma-plasmashell.service`. Штатный профиль
`plasma-org.kde.plasma.desktop-appletsrc` остаётся доступным для обычной Plasma.
