# PLASMA-INSTALL-SHELL: Настраивать SberOS shell plugin при установке Plasma

- **Статус:** Готово
- **Обновлено:** 2026-10-27
- **Источник:** запрос пользователя «добавь это в скрипт установки» после отказа `install-and-restart.sh` из-за штатного `ExecStart`; [PLASMA-DEFAULT](PLASMA-DEFAULT.md), [PLASMA-RESTORE](PLASMA-RESTORE.md).
- **FT/UI:** `UI_SBEROS_PANEL_USSURI_1.1`; изменяется способ запуска shell, интерфейс не меняется.
- **Сценарии:** `03-01` (основная панель), `02-02` (запуск приложений).
- **Зависимости:** пользовательская `plasma-plasmashell.service`, `install.sh`, `restore-plasma.sh`.
- **Неясности:** нет.

## Критерии готовности

- [x] Обычный vendor unit автоматически получает отдельный drop-in SberOS при обычной установке с перезапуском.
- [x] Drop-in с неизвестным содержимым не перезаписывается.
- [x] `--dry-run` показывает требуемую настройку службы, не записывая её.
- [x] При ошибке reload/restart новый drop-in удаляется и выполняется попытка восстановить прежний shell.
- [x] Инструкция и реестр задач отражают новое поведение.

## Результат и проверки

`install-and-restart.sh` теперь создаёт
`$XDG_CONFIG_HOME/systemd/user/plasma-plasmashell.service.d/sberos-shell.conf`
(по умолчанию под `~/.config`) с командой запуска SberOS shell. Скрипт проверяет
эффективный `ExecStart`, затем перезапускает службу. Конфигурация создаётся после
успешной установки пакетов; при неудаче перезапуска удаляется только drop-in,
созданный этим запуском. Существующий точный drop-in используется повторно,
другой не изменяется. `--dry-run` не меняет ни пакеты, ни конфигурацию службы.

Изменение проверено `bash -n` и `git diff --check`. Системная пользовательская
служба не перезапускалась, поведение проверено только по коду; сценарии `03-01`
и `02-02` следует подтвердить после запуска в пользовательской сессии.

Соответствие мокам не затрагивалось: изменена конфигурация запуска оболочки.
Sirca и Quickshell не изменялись.

## Следующий шаг

После установки проверить активность `plasma-plasmashell.service`, её `ExecStart`
и отображение SberOS панели в текущей сессии.
