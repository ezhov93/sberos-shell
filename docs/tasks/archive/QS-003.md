документацию из рабочей копии Quickshell. Удалить также ограничение на среду
проведения проверок. Сохранить CMake/`kosctl` пути для
поддерживаемых обычных дистрибутивов, общие защитные проверки и сторонние лицензии.
Не менять исходный эталон в `refs/NextKde/`.
