- **Источник:** прямой запрос пользователя от 2026-10-22
- **Требования FT/UI:** нет; погода в Sirca — дополнительная функция, не отдельный сценарий исходного реестра

- **Зависимости:** —

## Цель

Полностью удалить погодную функцию из Sirca Shell: сетевой и геолокационный сервис,
карточку календаря, индикатор панели, настройки места и единиц, регистрацию и тестовые
заглушки. Старые значения погоды в пользовательском конфиге не должны создавать
несуществующий элемент панели; сами пользовательские данные не переписываются.

## Критерии готовности

- [x] В Sirca нет запросов прогноза, Geoclue-поиска мест, погодной карточки или настройки погоды.
- [x] Сборка больше не включает погодные исходники/виджет, старые погодные ID в раскладках панели игнорируются.
- [x] Проверки и документация настроек отражают удалённую функцию.
- [x] `refs/NextKde/` и `quickshell/` остаются без изменений этой задачи.
- [x] Sirca собирается; изолированная проверка настроек проходит.

### Готовность по проектам

- Sirca [x] Погодный код и точки входа удалены, конфиг совместим со старыми списками виджетов, сборка и изолированная проверка настроек прошли.
- NextKDE [x] Не входит в область; запрос уточнён пользователем как относящийся к Sirca, проверка влияния выполнена по отсутствию изменений в `quickshell/` и `refs/NextKde/`.

## Неясности

Нет. Значки солнца, используемые для выбора светлого/тёмного режима, остаются: это не прогноз погоды.

## Проверки и результат

`cmake -S shell/shell -B /tmp/sberos-shell-build -DCMAKE_BUILD_TYPE=Debug` и
`cmake --build /tmp/sberos-shell-build -j 4` прошли; собран бинарник
`/tmp/sberos-shell-build/bin/sirca-shell`. Изолированная проверка настроек
`python3 shell/shell/tests/run-settings-tests.py --output /tmp/sber-settings-check-weather-removal`
прошла: **9 passed, 0 failed** на Qt 6.11.2/offscreen. Есть ожидаемые предупреждения
плагина offscreen о неподдерживаемом `raise()` и сообщение тестовой среды об
отсутствующем файле перевода. Полный запуск оболочки в Wayland не выполнялся.
`git diff --check` прошёл. В коде остались только имена системных иконок погоды,
используемые для управления светлым/тёмным режимом, и совместимость со старыми
погодными ID раскладок.
