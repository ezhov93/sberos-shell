- **Статус:** Готово

## Цель и критерии готовности

Перенести основной интерактивный установщик и удалитель оболочки на Python, сохранив проверки системы, выбор компонентов, подтверждения, режим без изменений, журналирование, откат внешних настроек и безопасное восстановление панелей Plasma.

### Готовность по проектам

- Sirca [x] Основные entrypoint-файлы установки/удаления перенесены на Python; README описывает их; синтаксис и документированные dry-run режимы проверены.
- NextKDE [x] Влияния нет: `refs/NextKde/` не вызывается установщиком Sirca и остаётся сравнительным эталоном.

## Результат и проверки

`install.py` переносит проверки окружения, выбор `shell` / `look` / `full`, действия компонентов, dry-run и журналирование. `uninstall.py` сохраняет поэтапные подтверждения, восстановление панелей, откат внешних настроек и удаление shell. Удалены прежние основные `install.sh` и `uninstall.sh`; вложенные скрипты сборки и установки самой оболочки оставлены без изменений. README использует новые entrypoint.

Проверки 2026-10-23: Python syntax compilation прошла; `--help` обоих entrypoint прошёл; `install.py --dry-run --preset shell|look|full --yes` и `uninstall.py --dry-run --yes` прошли без выполнения изменений. Dry-run `full` сообщил, что в текущем окружении нет Plasma/KWin; реальная установка, удаление и GUI не запускались.
