## Цель и критерии готовности

Исправить подтверждённые поведенческие дефекты аудита QML Sirca Shell и проверенные высокоуверенные замечания линтера. Низкоуверенные эвристики классифицировать, не считать дефектом без подтверждения. `shell/desktop/`, сборочные копии, UI Kit и NextKDE вне области.

- [x] Дочернее меню Сбер остаётся видимым и имеет положительную ширину у обоих краёв экрана.
- [x] Индикатор раскладки не переключает пустой список и не вычисляет индекс по модулю нуля.
- [x] Переключатель окон получает модель при создании, до первого Alt+Tab.
- [x] Подтверждённые поведенческие замечания аудита устранены; оставшиеся статические предупреждения сгруппированы ниже.
- [x] Сборка Sirca Shell проходит; линтер запускается, остаточные предупреждения классифицированы; Wayland-сценарии отмечены как непроверенные.

### Готовность по проектам

- Sirca [x] Исправления и проверки `shell/shell/` завершены по критериям выше.
- NextKDE [x] Не входит: область запроса ограничена Sirca Shell; `quickshell/` не изменяется.

## Проверки и результат

- `cmake --build shell/shell/build -j4` — успешно.
- `git diff --check` — успешно.
- `qt_qml_lint.py --summary --qmllint` по `shell/shell/qml/` и `shell/shell/tests/`, с import-путями UI Kit и Sirca — qmllint запущен; осталось 1300 сообщений в 81 группе/паре правила и текста. Основные группы: типовые эвристики (`var`, динамические модельные роли), намеренные императивные присваивания в обработчиках, неуточнённый scope, порядок/форматирование и отсутствующие в локальной среде типы приватных KDE-модулей. LDR-1 остаётся ложным срабатыванием на `loader.item?.implicitWidth`: optional chaining безопасно обрабатывает `null`, но правило линтера его не распознаёт. Массовые механические изменения могут нарушить динамические контракты. Список сохранён в `/tmp/shell-qml-final-lint.txt`.
- Тесты поведения и проверка на Wayland не запускались; визуальная проверка не проводилась.

Исправлено: ширина и сторона дочернего меню Сбер; защита индикатора раскладки при нуле раскладок; ранняя модель Alt+Tab; затенение QML-свойств `visibility`/`enabled`/`scale`; дочерний `MouseArea` внутри layout; guard для `Loader.item`; Qt 6 `MultiEffect` вместо старого эффекта маски; предпочтительная высота layout, строгие сравнения и размеры изображений.
