# SHELL-GLASS-EFFECT: Удалить пользовательские KWin-эффекты Sirca

- **Статус:** Готово
- **Источник:** прямой запрос пользователя от 2026-10-23 удалить `shell/kwin-effects/`, поскольку эффект больше не нужен.
- **FT/UI:** техническое удаление реализации; специфицированные сценарии не меняются.
- **Сценарии:** нет затронутых ID; визуальные поверхности остаются непрозрачными.
- **Зависимости:** нет.

## Критерии готовности

- [x] Каталог пользовательских KWin-эффектов удалён.
- [x] Оболочка больше не требует Glass effect, не передаёт панели с effect-specific scope и не отправляет данные `setLobes`/`clearLobes`.
- [x] Из Sirca удалена настройка blur behind через `KWindowEffects`; маски кликов, формы и layer-shell поверхности сохранены.
- [x] Установщик больше не предлагает, не собирает и не устанавливает эффекты.
- [x] README и интеграция Spotify описывают непрозрачный вид без Glass Key.
- [x] Поиск по исходникам подтверждает отсутствие активной зависимости; старый uninstall cleanup оставлен только для удаления плагинов, записанных прежним установщиком.
- [x] NextKDE вне области: он использует собственный исходный эталон и не зависит от `shell/kwin-effects/`.

## Проверки и ограничения

- Поиск по `shell/shell` подтвердил отсутствие активных ссылок на `org.kde.KWin.Glass`, `setLobes`, `clearLobes`, `KWindowEffects`, `setBlurRegion` и удалённые blur-настройки дока.
- `cmake --build build -j 4` из `shell/shell/` — успешно. GUI-проверка поверхностей не запускалась.
- Изменения пользовательского каталога плагинов или настроек KWin вне репозитория не выполнялись.

Следующий шаг: при необходимости удалить уже установленный ранее плагин через прежний uninstall cleanup или вручную из настроек KWin; визуальную проверку выполнить отдельно.
