# ATP-001: native surfaces, 26.10.2026

Сценарии: `03-01`, `02-02`, `05-01`–`05-06`, `05-10`, `07-01`, `09-19`, `09-24`.
Qt 6.11.2, Plasma 6.7.4, Wayland, светлая тема, экран 2560×1440, DPR 1.
Без проверки тёмной темы, масштабируемости, вариантов высоты или сетки.

`before-*` — предыдущий этап Smart Panel; `after-*` — этот этап. Launchpad
использует реальные обои Desktop, предварительно захваченные из WallpaperItem
для image-provider. Снимок launcher подтверждает полноэкранное содержимое,
blur/затемнение обоев и резкие значки приложений. `geometry.json` содержит
глобальные координаты с учётом начала экрана y=107.

Поиск 456×653 и уведомления 456×354: нижний край экрана минус 8 px.
Настройки 488×540: справа 16 px, нижний край экрана минус 88 px.
Меню Сбера 72×216 проверено отдельно, нижний край экрана минус 8 px.

`qml-lint.log`: 20 изменённых QML, qmllint --bare exit 0 с предупреждениями.
`sync-smart-panel.py --check`: 168 ресурсов. Qt-пробник KSvg QRegion:
`QRect(16,8 2528x72) 288 true false false true` — остров включён, промежуток
и внешний скруглённый угол исключены, центр поиска включён.

Снимки QML не показывают композицию KWin за панелью. Видимый blur островов,
живой ввод, внешние клики и действия реальных уведомлений остаются непроверенными.
Во время захвата системные переключатели не активировались. Временные процессы
захвата завершены; отдельный пользовательский предпросмотр оставлен запущенным.

`native-surfaces.patch` — точный текстовый diff этого этапа относительно снимка
перед ним, отдельно от предыдущего переноса пакетов; `changed-files.txt` — его
состав. Patch проверен обратным применением без изменения рабочего дерева.
