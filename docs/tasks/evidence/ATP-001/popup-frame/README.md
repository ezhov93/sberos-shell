Особенность Plasma 6.7: DialogBackground содержит FrameSvgItem, который задаёт
и поля resize, и область blur/contrast. Простая opacity=0 скрывает рисунок,
сохраняя оба эффекта с прежними полями. Поэтому общий адаптер подставляет
собственный девятисегментный SVG с нулевыми после округления полями. Отдельно
обнуляются native shadow tiles через borders окна, затем восстанавливаются
все сегменты самого FrameSvgItem для скруглённой маски. Обработка bordersChanged
повторяет это после штатного позиционирования; защита исключает рекурсию.
Поля округляются и при вычислении anchor. После смены размера запрашивается
повторное позиционирование; межоконный отступ 8 px сохраняет прежнюю геометрию.

Это привязка к внутреннему DialogBackground Plasma 6.7; после обновления
libplasma нужно повторить целевую проверку рамки/маски/курсора. Исходники KDE:
[AppletPopup](https://github.com/KDE/libplasma/blob/Plasma/6.7/src/plasmaquick/appletpopup.cpp),
[DialogBackground](https://github.com/KDE/libplasma/blob/Plasma/6.7/src/plasmaquick/dialogbackground_p.cpp),
[DialogShadows](https://github.com/KDE/libplasma/blob/Plasma/6.7/src/plasmaquick/dialogshadows.cpp).

`qmllint --bare -I /usr/lib/x86_64-linux-gnu/qt6/qml` изменённого адаптера —
exit 0 без предупреждений; sync-check — 172 ресурса; XML-разбор пяти SVG — успешно.
Общая сборка/CMake для KPackage не требуется. Тёмная тема, масштабируемость,
разные размеры, сетки и массовые прогоны не выполнялись по согласованной границе.

Снимки KWin получены на текущих обоях. Под нижней частью popup виден размытый
остров исходной пользовательской панели; отдельный количественный тест blur
и маски ввода промежутков панели не проводился. Пользовательская Plasma и её
раскладка не менялись. Capture отключал hideOnWindowDeactivate только в своей
копии, поэтому внешний клик не считается проверенным. Tab/Esc проверялись
синтетическими событиями в настоящем окне, физический ввод отдельно не проверен.
Старые предупреждения сторонних страниц Battery/Bluetooth и недоступных сервисов
частного D-Bus не относятся к рамке и остаются ограничением интеграции.
Все процессы захвата и пробника завершены; сведения об отдельном оставленном
предпросмотре записаны в карточке ATP-001.
