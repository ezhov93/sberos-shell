# ATP-001: единое поле поиска и клавиатурный фокус

Сценарии `02-02`, `05-01`–`05-06`, `05-10`; Qt 6.11.2 / Plasma 6.7.4 /
KWin / Wayland, 2560×1440, DPR 1, светлая тема. Мок: `6e48fb5`.
До исправления: `6f02122`.

- `before-user.png` — предоставленный пользователем снимок: под выдачей
  сохранялся прозрачный ряд от удалённого поля, через него видна другая панель.
- `after-empty-light.png`, `after-typed-light.png` — содержимое QML после
  исправления; выдача 456×589 и остров 456×72 разделены зазором 8 px.
  Это grab QML/окна; фон за native окном сам по себе ими не проверяется.
- `after-install-live.png` — кадр рабочего стола после установки пакетов и
  перезапуска штатной Plasma-службы 27.10.2026; на основной панели видны жабка,
  строка поиска и индикатор раскладки. Снимок включает два дисплея и окно Codex.
- `geometry.json` — native окно 456×669 в (1052,763). Остров остаётся
  в (1052,1360), поле — в (1120,1368), то есть внутри прежней панели.
- `verification.log` — фактический `QGuiApplication::focusWindow()` совпал
  с окном, содержащим единственный TextField. Клавиши QtTest ввели запрос,
  который дошёл до Milou, затем Ctrl+A заменил текст; Esc закрыл поиск.
  Повторное открытие кликом и поиск → уведомления → поиск прошли.
  После ввода оба соседних Button оставались видимыми.
- Native KSvg-маска включает выдачу и остров, исключает зазор и скруглённый
  угол. Проход кликов через зазор отдельно не проверялся.

`input-probe.cpp` — временный QtTest-плагин, собранный только в `/tmp`.
События отправлялись в настоящее окно plasmashell, текст не подставлялся
через `setProperty`. Физическая клавиатура отдельно не инструментировалась.
Capture отключал hideOnWindowDeactivate в своей копии для устойчивого захвата;
внешний клик этой проверкой не подтверждён. В живом предпросмотре используется
обычное закрытие Plasma при деактивации окна.

Указатель раскладки остаётся видимым; при отсутствии сервиса в частном D-Bus
предпросмотра показывает «—» и недоступен для переключения. Реальные поиск и
уведомления зависят от доступных сеансовых сервисов. Тёмная тема, масштабирование,
разные размеры экранов и массовые прогоны не выполнялись в согласованных границах.
Все процессы проверки завершены; отдельный пользовательский preview записан в ATP-001.
