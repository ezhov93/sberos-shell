Ограничения:

- У тестовой Plasma частный D-Bus. Проверены загрузка и отрисовка; переключатели,
  поступление/действия реальных уведомлений, запуск/сворачивание реальных окон,
  живые Esc/Tab, внешние клики и сервисные ошибки не считаются принятыми.
- VPN явно недоступен; календарь не имеет backend встреч; настройки меню запускают
  `systemsettings`. Native страницы устройств ещё не приведены полностью к моку.
- Native popup открываются над панелью; в HTML нижний ряд является частью
  раскрывающейся поверхности. DashboardWindow использует рабочую область
  2560×1352, не полноэкранные 2560×1440. Это конкретные расхождения.
- Blur, маска ввода в промежутках островов, strut и маски размытия требуют
  проверки/доработки с реальным KWin-сеансом. Эти снимки не подтверждают blur.
- В журнале остаются предупреждения сторонних страниц/отсутствующих сервисов
  и `qt.svg: Invalid path data; path truncated`. По сообщениям Qt источник этих
  предупреждений не локализован; просмотрены реально полученные системные значки.
- Попытка прочитать версию Plasma в offscreen вызвала сбой CLI; она прекращена,
  повтор не выполнялся. Версия взята из метаданных пакета. Приёмка использует
  успешные отдельные Wayland-запуски, не offscreen plasmashell.

Коммит не создан: перед работой перенос всего дерева Plasma уже был выполнен
в рабочем дереве, новые каталоги оставались untracked, старые — удалёнными.
Изолированный source-коммит включил бы чужой незакоммиченный перенос и реализацию.
`adaptation.patch` содержит только этот этап; проверка его обратного применения
подтверждает соответствие рабочим файлам. Общий статус ATP-001 — «В работе».
