# Установка SberOS-панели Plasma

В этой рабочей копии поддерживается установка только пользовательских компонентов
SberOS. Полный upstream-комплект AeroThemePlasma сохранён в `../refs/aerothemeplasma/`.

Из корня репозитория запустите:

```sh
bash plasma-theme/install.sh --dry-run
bash plasma-theme/install.sh
```

Скрипт устанавливает shell и шаблон панели SberOS, пять собственных плазмоидов,
Plasma Drawer, KDE Control Station и файловый поиск. Системные файлы и темы не
меняются; существующие пользовательские пакеты перед обновлением сохраняются в
каталоге резервных копий.

Для замены штатных часов в активной панели сначала проверьте:

```sh
bash plasma-theme/install.sh --dry-run --activate-clock
```

Затем запустите ту же команду без `--dry-run`. Конфигурация панели сохраняется
перед изменением. После установки перезапустите Plasma, чтобы перечитать пакеты.
