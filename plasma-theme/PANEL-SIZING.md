# Геометрия панели Plasma

Актуальный контракт после запроса выровнять layout и плазмоиды по моку —
[SMART-PANEL.md](SMART-PANEL.md). Панель теперь занимает ширину экрана,
острова имеют целевую высоту 72 px внутри 88 px общей полосы, поиск центрирован,
крайние зоны закреплены у краёв. FitContent предыдущего этапа заменён:
компенсационное свободное место находится по сторонам поиска.

`AppletSizeHints.qml` сохраняет ограничения размера, `PanelLayoutMetrics.qml`
распределяет доступную ширину без перекрытия зон. Компоненты читают выделенную
толщину содержимого; фон общего острова принадлежит containment.

По указанию пользователя в текущей задаче **не проверяются масштабируемость,
высоты, разные сетки/экраны и тёмная тема**. Старый `run-panel-sizing.py`
сохраняется как инструмент предыдущего этапа; запускать его для этой доработки
не следует. Согласованная проверка — только цель в светлой теме, команды и
ограничения указаны в SMART-PANEL.md, история — в
[ATP-001](../docs/tasks/ATP-001.md).
