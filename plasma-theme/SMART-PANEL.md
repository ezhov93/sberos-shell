# Smart Panel в Plasma

Рабочая реализация панели и связанных плазмоидов. Визуальная цель —
[HTML-мок](../docs/mock/smart-panel/), ход работы — [ATP-001](../docs/tasks/ATP-001.md).
Происхождение сторонних пакетов и их лицензии сохраняются в каталогах пакетов.

## Компоновка и взаимодействия

Панель занимает ширину экрана. Стандартная толщина — 88 логических px:
острова 72 px и верхний/нижний отступ по 8 px, как в сцене мока 1920×1080.
Ранее сохранённая пользователем высота не перезаписывается; 88 px — значение
новой стартовой раскладки и схемы конфигурации.
Сбер и приложения закреплены слева, системный остров — справа, поиск шириной
456 px центрирован по экрану. Свободное место остаётся между этими зонами.
Drawer и задачи имеют общую поверхность, быстрые настройки и часы — другую.
Общая полоса фона Plasma не рисуется. `IslandMask.qml` собирает QRegion только
из скруглённых островов; `PanelView` использует её для blur и ввода, оставляя
промежутки свободными. SVG создаёт Python 3 в XDG cache, без бинарного плагина.

Компоновку задают одновременно shell `contents/layout.js`, шаблон панели,
`Panel.qml`, containment `sberos.panel` и компактные представления апплетов.
Состав панели остаётся фиксированным. Существующие applet/KPackage ID сохранены.
При открытии applet панель закрывает остальные popup, включая окно Drawer.

- Меню Сбера: четыре кнопки, дочерние пять действий питания, Esc и видимый
  клавиатурный фокус. Действия выполняются штатным SessionManagement.
  В текущей Plasma настройки запускают `systemsettings`, терминал — `konsole`;
  собственное окно настроек оболочки здесь ещё не подключено.
- Launchpad: исходный значок мока, плоская сетка установленных приложений,
  фильтрация той же сетки только по имени, нижняя строка поиска, пустая выдача.
  Значки приложений берутся из desktop entries, демонстрационные программы не
  подставляются. Точки страниц отображают реальное число приложений.
  Открытие через `DashboardWindow.toggle()` действительно полноэкранное. Фон —
  текущий WallpaperItem этого экрана, переданный Desktop через WorkspaceSurfaces.
  Файловые изображения используются напрямую; обои из image-provider захватываются
  перед открытием. Размывается и затемняется только фон, значки остаются резкими.
- Локальный поиск в режиме панели: отдельный `SmartSearchPopup.qml`, группы
  приложений и локальных документов, реальные результаты Milou и недавние
  элементы из существующей истории. Enter запускает первый результат, Esc
  закрывает popup. Наличие индексатора определяет доступность поиска документов.
  Остальные режимы стороннего виджета сохраняют прежнее представление.
- Задачи: hover/pressed/focus, точки открытых окон, разделитель незакреплённых,
  меню и прокрутка внутри доступного места. Активная кнопка сворачивает окно,
  неактивная показывает; средняя кнопка запускает новый экземпляр. Первые два закрепления защищены
  существующим контрактом; значение preferred://browser зависит от окружения.
- Быстрые настройки: 488×540, исходные символы, подписи звука и дисплея,
  постоянные места недоступных регуляторов, реальный заряд и профиль питания,
  возврат из дочернего уровня по Esc. Плитка уведомлений переключает штатный
  режим «Не беспокоить», внешнее подавление уведомлений блокирует ручной toggle.
  Авиарежим вызывает native Handler. VPN пока явно недоступен.
- Аватар Оськи открывает отдельный список уведомлений со счётчиком, очисткой,
  закрытием карточки и действием приложения. WatchedNotificationsModel наблюдает
  за сервером Plasma и не регистрирует конкурирующий сервер. В отсутствие
  сервиса показано состояние недоступности. Нижнее поле переводит в поиск.
- Календарь: 344×382 для пяти недель, исходные стрелки, выбор даты и переходы
  месяцев. Поле «Только даты» явно указывает отсутствие событийного backend.
- Переключатель языка использует штатный KeyboardLayout и скрыт, если сервис
  не предоставил список раскладок. В изолированном D-Bus его работа не проверяется.

По уточнению пользователя от 26.10.2026 в текущий этап Plasma **не входят**
оформление дочерних страниц Wi‑Fi, Bluetooth и питания по моку, подключение VPN
и событий календаря. Существующие нативные страницы остаются доступными;
VPN обозначен недоступным, календарь работает с датами. Эти пункты не являются
незакрытыми критериями текущей адаптации. Уточнение относится к `plasma-theme/`
и не меняет объём Sirca/Quickshell.

## Палитра и графика

`shared/SmartPanelTheme.qml` хранит материалы, цвета текста, состояния и фокус
из `styles.css` мока. Это адаптер к теме Kirigami/Plasma, без нового бинарного
плагина и зависимости KPackage от сборки UI Kit. API UI Kit изучен; его запуск
требует QApplication и своих импортов/ресурсов. Существующие системные сервисы
и контролы Plasma сохраняются; UI Kit этой задачей не расширяется.

Скрипт `tools/sync-smart-panel.py` доставляет одинаковые токены в самостоятельные
KPackage-пакеты и копирует графику из мока. В SVG символах удаляются служебные
ID и нормализуется начало координат, контуры не перерисовываются.
Для монохромных символов генерируются варианты цветов палитры;
`SmartPanelIcon.qml` открывает именно файлы, обходя подмену одноимённых значков
через KIconLoader. VPN и bell копируют path из `mock.js` (у них нет отдельного SVG). Аватар содержит
исходный встроенный PNG; `OskaAvatar.qml` делает круговую маску, которую QtSvg
не применяет к исходному image/pattern. SHA-256 ресурсов фиксирует
`shared/artwork-manifest.json`. При изменении исходников:

```sh
python3 plasma-theme/tools/sync-smart-panel.py
python3 plasma-theme/tools/sync-smart-panel.py --check
```

## Проверка в согласованных границах

По уточнению пользователя 26.10.2026 не проверять масштабируемость, разные
высоты, размеры экрана, варианты сеток и тёмную тему. Поддержка тёмной палитры
остаётся в коде, визуальная приёмка касается только светлой темы.

```sh
QT_QPA_PLATFORM=offscreen timeout 15s /usr/lib/qt6/bin/qmltestrunner \
  -input plasma-theme/tests/tst_panellayout.qml PanelContentSizing::test_targetMockLayout
python3 plasma-theme/tests/capture-smart-panel.py --source plasma-theme \
  --output /tmp/sber-plasma-light-check --states panel quick calendar
```

Захват использует отдельный профиль Plasma и частный D-Bus в текущем Wayland,
не устанавливает пакеты в пользовательские каталоги и завершает собственную
группу процессов. `hideOnWindowDeactivate` в снимках отключён только в тестовой
копии, чтобы смена активности внешних окон не мешала захвату. Это проверка
отрисовки, а не работы сервисов, фокуса или закрытия по внешнему клику.

`SmartPopupPlacement.qml` размещает меню Сбера, поиск и уведомления над
центральным островом с зазором 8 px; настройки и календарь — над панелью.
Стабильный host поиска переключает поиск/уведомления внутри одного popup.
Координаты поиска, уведомлений, настроек и полноэкранность Launchpad подтверждены
целевыми снимками Wayland; QRegion отдельно проверена на островах, углах и промежутках.
Доказательства: [native-surfaces](../docs/tasks/evidence/ATP-001/native-surfaces/).

Ограничения приёмки: видимое размытие обоев за островами, живой ввод с клавиатуры,
реальные устройства/окна, поступление/действия уведомлений и strut требуют
проверки с сервисами пользовательского сеанса. Захват отдельного QML-элемента
не показывает результат композиции KWin за ним.

Для дальнейшего интерактивного редактирования QML можно подключить QML Preview
MCP; он требует Qt 6.12 или новее. В этом окружении использован фактический
Plasma/QML runtime Qt 6.11.2.

## Нативная рамка popup

Общий `SmartPopupPlacement.qml` подставляет в DialogBackground Plasma 6.7
`shared/SmartPopupFrame.svg`: радиус 24 px, нулевые после округления поля.
Это убирает внешнюю область contrast/blur и зоны resize вокруг содержимого.
Native shadow tiles отключены отдельно; все углы маски остаются включёнными.
SVG доставляется в четыре KPackage тем же `sync-smart-panel.py`.
Размеры и координаты содержимого сохранены. Доступ к вложенному FrameSvgItem
зависит от внутреннего устройства libplasma 6.7; после обновления Plasma
повторять целевую проверку рамки, маски и курсора.
[Снимки KWin до/после и результаты](../docs/tasks/evidence/ATP-001/popup-frame/).
