# SberOS Applications

Один апплет Launchpad и закреплённых/запущенных приложений.
KPackage ID: `io.gitgud.wackyideas.smarttasks`.
Модель задач, закрепления и +N принадлежат `main.qml`; полноэкранное меню
и модель установленных приложений — `Launchpad.qml` / `MenuRepresentation.qml`.
Состав панели и установка: [Smart Panel](../../SMART-PANEL.md).

Launchpad основан на Plasma Drawer Connor Popp
(https://github.com/p-connor/plasma-drawer) и KDE Kicker.
Сохранены заголовки авторства и лицензия GPL-2.0-or-later;
полный текст находится в `LICENSES/GPL-2.0.txt`.
Переработка SberOS: плоская сетка и поиск, фон рабочего стола,
объединение кнопки Launchpad и Task Manager в одном апплете.
