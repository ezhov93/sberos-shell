# PANEL-001: проверка пятизонной компоновки

Дата: 2026-10-22. [Задача](../../../../docs/tasks/PANEL-001.md),
[ADR-0008](../../../../docs/adr/0008-unified-bottom-panel.md),
[правила](../../../../docs/rules/unified-panel.md).

## Изменение и границы

Одна нижняя поверхность содержит пять отдельных округлых непрозрачных блоков:
Сбер, приложения, Оська, индикаторы, быстрые настройки/календарь.
Оська расположена по центру экрана, ширина области индикаторов зарезервирована;
приложения растут только до левой границы центра. Новые фоны используют UI Kit,
фонового blur у unified нет. Маска объединяет отдельные блоки и открытый popup,
а не всю полосу между ними. Для этого `Shell.setShape` принимает необязательный
`blur` (по умолчанию true), сохраняя маску и при false. Split сохраняет прежний вид.

Это компоновка: кнопка Сбер пока открывает настройки shell, центр вызывает
существующие поиск/уведомления и переключает раскладку. Меню Сбер, полноценная
Оська, правила ситуативных индикаторов и +N остаются отдельными задачами.
Существующие виджеты, трей, показ рабочего стола и рабочие пространства пока
переиспользуются в зарезервированной области индикаторов. Полная перекраска
остальных окон/внутренних панелей и удаление старых настроек — SHELL-001.

## Окружение

- Qt 6.11.2, Linux x86_64, GCC 16.2.0.
- Снимки: offscreen/software, виртуальный экран **1920×1080**, масштаб 1.
- Интеграция: KDE/KWin Wayland, eDP-1, логическая геометрия **1920×1200**,
  физический режим 3840×2400, масштаб 2, один экран.
- Только ширина 1920 px по временному решению ADR; 1280/1440 отложены.
- Временные XDG_CONFIG_HOME/XDG_DATA_HOME; глобальные сочетания не захватывались,
  установщик и переключение Plasma не запускались. Все тестовые процессы завершились.

## Результаты

- Сборка `cmake --build /tmp/sberos-shell-build -j 4` прошла.
- `run-panel-smoke.py --layout` и `--layout --wayland`: PASS, exit 0.
- Проверены пять непересекающихся зон, центр экрана, неизменность центра и
  системной зоны при появлении индикатора записи, изменение размера ячеек,
  открытие календаря/быстрых настроек/лаунчера, возврат split → unified.
- В Wayland начальная модель содержит 4 закрепления; временный стресс-список
  содержит 30. При ячейке 72 px содержимое занимает 2256 px, блок приложений
  ограничен 652 px и не перекрывает Оську. Приложения не запускались.
- Через временный читающий скрипт KWin проверена рабочая область активного экрана:
  до панели 1920×1156, с панелью 1920×1080, после закрытия снова 1920×1156.
  Разница 76 px соответствует dockHeight 60 + двум отступам по 8 px; исходная
  панель Plasma оставалась работающей. Скрипт выгружен, окна не перемещались.
- Скриншоты до/после обеих тем просмотрены. У новых блоков нет сплошной подложки
  между зонами; белые системные значки получили читаемый плоский вариант.
- Проверка API-контракта UI Kit и `git diff --check` прошли.

Изменённые области: `03-01`, `04-07`, `04-09`, `09-02`, `09-19`, `09-24`;
точки входа `02-02`, `05-11`, `07-01` затронуты переносом. Это не полная
приёмка этих сценариев. Новая логика приложений/сети/уведомлений не заявляется.

## Ограничения

В offscreen модель задач возвращает 0 строк, поэтому на снимках нет закреплённых
приложений: заполнение и переполнение проверены отдельно в Wayland.
Снимки содержат прозрачную область над панелью; просмотрщик может показывать её
чёрной. Снимки «до» сделаны предыдущей сборкой до изменения компоновки при 1920 px.

В Wayland callback `grabToImage` не завершался (с программным и обычным рендерингом);
первый запуск завершился ошибкой сценария, следующий — timeout 25 s. Это не
записано как успешная визуальная проверка Wayland. Финальный Wayland-сценарий
проверяет состояния без захвата снимков, снимки и темы проверяются offscreen.

Не проверены hotplug, второй монитор, масштабирование кроме указанных режимов,
фактическая активация окон, DnD и указатель в зазорах. Сохранены известные
предупреждения ручного запуска: ограничения window-management/fake-input,
занятый Plasma сервер уведомлений, отсутствующие глобальные сочетания и Glass.
Отсутствие Glass больше не мешает фонам unified, но общая стартовая диагностика
пока содержит старое предупреждение (удаление — SHELL-001).

## Воспроизведение

```sh
cmake --build /tmp/sberos-shell-build -j 4
python3 shell/shell/tests/run-panel-smoke.py --layout --output /tmp/sber-panel001-after
python3 shell/shell/tests/run-panel-smoke.py --layout --wayland --output /tmp/sber-panel001-wayland
python3 ui-kit/tools/api_contract.py --check
```

Wayland-команда кратковременно показывает тестовую панель и popup в текущей
сессии, требует логической ширины 1920 px и завершает процесс автоматически.
Для чтения рабочей области до/во время/после отдельного запуска:

```sh
/usr/bin/python3 shell/shell/tests/panel/work-area.py /tmp/panel-area.json
```

Нужны python3-dbus и python3-gi. Скрипт создаёт временный сервис/скрипт KWin,
только читает область активного экрана и выгружает скрипт в finally.
