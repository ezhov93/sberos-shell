# Проверка единой панели

Дата: 2026-10-22. Решение: [ADR-0008](../../../../docs/adr/0008-unified-bottom-panel.md).
Требования и область регрессий: [единая панель](../../../../docs/rules/unified-panel.md).

## Окружение и способ проверки

Linux x86_64, Qt 6.11.2, GCC 16.2.0, Qt Quick software, `offscreen`, экран
800×800. Используются собранный `sirca-shell`, настоящий `Main.qml`, `ScreenSet`,
`UnifiedPanel` и существующие системные компоненты. Конфигурация и данные
приложения находятся во временном каталоге, D-Bus-сессия отдельная.
Панели текущего рабочего стола не переключаются, собственные глобальные
сочетания не захватываются. Установщик не запускается.

В тестовой шине нет полноценного KWin и контроллера активностей. Для диагностики
у первого экземпляра модели отключён фильтр активности; модель всё равно
вернула 0 строк. Реальные задачи и закрепления на снимках не представлены;
из этого нельзя делать вывод об успешной проверке запуска и переключения окон.

## Воспроизведение

Из корня проекта, после сборки UI Kit:

```sh
cmake -S shell/shell -B /tmp/sberos-shell-build -DCMAKE_BUILD_TYPE=Debug
cmake --build /tmp/sberos-shell-build -j 4
python3 shell/shell/tests/run-panel-smoke.py --output /tmp/sber-panel-check
python3 shell/shell/tests/run-settings-tests.py --output /tmp/sber-panel-settings-check
python3 ui-kit/tools/api_contract.py --check
git diff --check
```

Runner требует `dbus-run-session`, `timeout` и возможность создать локальный
сокет тестовой шины. Его отдельный таймаут — 25 секунд. Подробный журнал
сохраняется в каталоге вывода. Параметр `--binary` позволяет указать другой
путь к собранной оболочке.

## Что ещё проверить в Wayland

- Реальный список окон, запуск, активацию, групповые превью, закрепления и DnD.
- Переполнение задач, колесо и жесты прокрутки с большим числом окон.
- Резервирование места снизу, автоскрытие и полноэкранные приложения.
- Два физических монитора, смену primary и hotplug; конфигурация `screens.*.panel`
  и выбор/отключение панели проверены отдельным виртуальным двухэкранным тестом.
- Меню реальных приложений в трее, ответ на уведомление, фокус клавиатуры,
  полный обход Tab/Shift+Tab и экранный диктор.
- Режим редактирования в сеансе, системные службы и GPU-эффекты.

В изолированном журнале ожидаются предупреждения о масках offscreen, отсутствии
KWin, kglobalaccel, разрешений fake input и эффекта Glass. Общий `--check`
повторно не запускался: для этой задачи использована ограниченная smoke-проверка
созданного интерфейса вместо известного зависания общего режима.

## Дополнительная двухэкранная проверка

23.10.2026 прогнана `python3 shell/shell/tests/run-panel-smoke.py --menu` с двумя виртуальными
экранами 1920×1080. Проверены включённая панель на вторичном экране, перевод меню
Сбер на экран нажатой панели, маршрутизация клавиатурного переключателя на последний
активный экран, отключение панели на primary, работа панели вторичного экрана и
fallback глобальной команды на неё. Сборка прошла. Расширенный `kscreen-doctor -o`
подтвердил в Wayland включённые DP-7 (2560×1440) и DP-6 (портретный 1080×1920),
eDP-1 отключён. Проверку интерфейса с новым бинарником отложили, потому что в этой
сессии уже работает `sirca-shell.service` (PID 215367); второй экземпляр мог бы
создать конфликт панелей. Реальные Wayland/hotplug остаются непроверенными.

После установки новой сборки 23.10.2026 `sirca-shell.service` запущен на той же
сессии с DP-7 и DP-6: `ActiveState=active`, `NRestarts=0`, журнал подтвердил
загрузку QML и первый кадр панели. Отдельные панели и popup на обоих дисплеях,
смена primary, взаимодействия и hotplug на тот момент визуально не проверялись.

При живой проверке 23.10.2026 выяснилось, что дополнительный экран требует явного
`screens.DP-6.panel: true`; без этого настройка панель создаётся только на primary.
После включения настройки оболочка без перезапуска создала панель на DP-6. На
физическом портретном DP-6 пользователь подтвердил отображение панели, открытие
Sber-меню и его закрытие по Esc, а также открытие поиска по Meta+Space на том же
мониторе и закрытие поиска по Esc. Смена primary и hotplug остаются непроверенными.
