путь к библиотеке задаётся `SBER_QML_IMPORT_PATH` при конфигурации shell.

сведения об авторах сторонних компонентов не изменялись.

## Окружение

Linux x86_64, Qt 6.11.2, GCC 16.2.0, `QT_QPA_PLATFORM=offscreen`,
`QT_QUICK_BACKEND=software`; без сеанса KDE/Wayland. Проверки окна используют
реальные `Settings.qml`, `Config.qml` и собранные плагины UI Kit. Shell и
UserWidgets подставлены в память; реальные конфигурация,
сеть, обои и службы рабочего стола не изменяются. Шрифты — доступные в окружении Qt.

## Воспроизведение

Из корня рабочей области:

```sh
cmake -S ui-kit -B ui-kit/_build -DBUILD_WITH_CTEST=OFF
cmake --build ui-kit/_build -j 4
cmake -S shell/shell -B /tmp/sberos-shell-build -DCMAKE_BUILD_TYPE=Debug
cmake --build /tmp/sberos-shell-build -j 4
python3 shell/shell/tests/run-settings-tests.py --output /tmp/sber-settings-check
python3 ui-kit/tools/api_contract.py --check
```

Для ползунка отдельно:

```sh
mkdir -p /tmp/sber-slider-test/data /tmp/sber-slider-test/config
QT_QPA_PLATFORM=offscreen QT_QUICK_BACKEND=software \
    XDG_DATA_HOME=/tmp/sber-slider-test/data XDG_CONFIG_HOME=/tmp/sber-slider-test/config \
    /usr/lib/qt6/bin/qmltestrunner -input ui-kit/tests/tst_slider.qml -import "$PWD/ui-kit/_build/qml"
```

При включённом `BUILD_WITH_CTEST` и наличии Qt Test и qmltestrunner
тест ползунка также регистрируется в CTest как `test_slider_input`.
Для снимков исходного окна runner имеет `--baseline /путь/к/старому/Settings.qml`:
он только снимает кадры, без новых регрессионных тестов.

## Ограничения и пропущенные проверки

- Штатный `sirca-shell --check` в offscreen не завершился за 25 секунд
  (код timeout 124, итогового отчёта нет). В журнале — предупреждение Surface
  о перекрытии свойства visibility и сообщения KDE/offscreen. Причина зависания
  не установлена; успешной эту проверку считать нельзя.
- При первоначальной проверке конфигурация `BUILD_WITH_CTEST=ON` не прошла из-за отсутствующего GoogleTest.
  Тогда GoogleTest/CTest smoke-проверка плагинов не выполнялась. Позднее зависимость заменена на Qt Test; это отдельная проверка сборки. После этого конфигурация
  UI Kit возвращена к OFF и успешно собрана; QML-тесты выполнены напрямую.
- Не проверены реальная Wayland-сессия, декорации KWin, доставка D-Bus от
  лаунчера/ярлыка/быстрых настроек, системное применение обоев и сетевой поиск города.
- Обход фокуса проверен на представительной группе; полный обход всех разделов,
  экранный диктор, сенсорный ввод, масштабирование и другие версии Qt предстоят.

Результаты покрывают миграцию окна изолированно и не подтверждают готовность
всех сценариев DE.
